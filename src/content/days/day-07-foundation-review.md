## 오늘 배울 이유

변수·출력·연산 순서를 한 번에 회상해야 새 문법을 외우기 전에 빈틈을 발견할 수 있습니다. Day 07 "`기초 1주차 회상과 오류 찾기`"에서는 Python 코드의 실행 결과(`30분`)를 따라가며, `계산한 값을 문자열에 삽입함` 동작이 왜 필요한지 확인합니다. 이 동작이 빠지면 "`문자열 앞 f를 빼고 {minutes}를 글자 그대로 출력함`" 같은 문제가 생깁니다.

## 시작 전에 확인할 것

바로 앞선 [Day 06](/learn/day-06-conversion)에서 배운 "C 형변환과 나눗셈" 내용을 한 문장으로 말해 보세요. 이번 "`기초 1주차 회상과 오류 찾기`"에서 새로 달라지는 조건을 찾아보세요. 핵심 표현은 `f"`입니다.

## 머릿속 그림

값을 계산해 변수에 넣고 f-string의 중괄호를 실제 값으로 치환하는 세 단계를 분리합니다. Day 07에서는 아래 흐름 순서대로 상태가 바뀌고, 결과를 가르는 부분은 `f"`입니다.

```text
5*2=10  →  minutes=30  →  30분 출력
```

위 흐름에서 `f"` 부분이 실행되는 지점을 찾으면 읽는 값과 바뀌는 값이 나뉘어 보입니다. 마지막 출력은 `30분`입니다.

## 천천히 풀어보기

이번에는 세 동작을 섞지 말고 분리하세요. 먼저 `5 * 2 = 10`, 다음 `minutes = 20 + 10 = 30`, 마지막 `f"{minutes}분"`의 `{minutes}`를 현재 값 30으로 바꿔 `30분`을 출력합니다. 앞의 `f`는 중괄호 안 표현식을 계산해 문자열에 끼워 넣으라는 표시입니다.

`print("{minutes}분")`에서는 `f`가 없으므로 중괄호가 그대로 출력됩니다. `minutes = 15`로 바꾼 뒤 `f"{minutes + 5}분"`을 출력하면 20분입니다. 원래 변수 값 15 자체가 바뀌는 것은 아닙니다. 계산 결과와 문자열 모양을 별개로 생각해 보세요.

`print("{minutes}분")`에서는 `f`가 없으므로 중괄호가 그대로 출력됩니다. `minutes = 15`로 바꾼 뒤 `f"{minutes + 5}분"`을 출력하면 20분입니다. 원래 변수 값 15 자체가 바뀌는 것은 아닙니다. 계산 결과와 문자열 모양을 별개로 생각해 보세요.

## 문법을 예제로 보기

아래 Python 코드는 Day 07 "`기초 1주차 회상과 오류 찾기`"의 독립 예제입니다. 전체 2줄 가운데 핵심 부분은 `f"`이며, 실행 결과는 `30분`입니다.

```python

```



`f"` 부분이 실행될 때 읽는 값과 바뀌는 값을 한 줄씩 적어 보세요. 다음 `결과 예측과 작은 변경`에서는 이 부분이 달라집니다.

위 순서대로 실행한 최종 출력은 `30분`입니다. `5*2=10` 단계와 마지막 단계를 비교하면 입력과 출력의 관계가 보입니다.

## 다른 예제로 다시 이해하기

`minutes = 15; print(f"{minutes + 5}분")`은 `20분`을 보여 줍니다. 이 출력문은 `minutes`를 바꾸지 않으므로 곧바로 `print(minutes)`를 하면 15입니다. 중괄호의 계산값, 문자열로 합친 결과, 변수에 저장된 현재 값은 서로 다른 대상입니다. `f`를 빼면 `{minutes + 5}분`이 그대로 나타납니다.

## 결과 예측과 작은 변경

원본 실행 결과는 `30분`입니다. 아래 코드에서 원본과 달라지는 첫 줄을 표시하고, 그 줄의 변경 전후 값을 적어 보세요.

```python
minutes = 21 + 5 * 2
print(f"{minutes}분")
```

찾은 줄을 적용했을 때의 실행 결과를 먼저 예측해 보세요.

해설: 바뀐 코드의 실행 결과는 아래와 같습니다.

```text
31분
```

원본은 `30분`, 수정본은 `31분`이다. 첫 변경 줄 `minutes = 20 + 5 * 2`에서 `minutes = 21 + 5 * 2`로 바꾸면, 21에 10을 더한 31이 저장된 뒤 f-string이 그대로 끼워 넣어 출력한다.

## 자주 틀리는 지점

**확인할 실수: 문자열 앞 f를 빼고 {minutes}를 글자 그대로 출력함.** 정상 코드의 실행 결과는 `30분`입니다.

- 정상 줄: `print(f"{minutes}분")`
- 잘못된 줄: `print("{minutes}분")`

두 줄을 나란히 놓으면 정상 줄 `print(f"{minutes}분")`이 `값을 계산해 변수에 넣고 f-string의 중괄호를 실제 값으로 치환하는 세 단계를 분리합니다.` 설명과 맞고, 잘못된 줄은 `문자열 앞 f를 빼고 {minutes}를 글자 그대로 출력함` 쪽으로 어긋납니다. 결과가 예상과 다르면 `5*2=10`부터 `30분`까지 처음 어긋난 곳을 찾습니다.

## 다른 언어로 옮기기

세 언어에서 지켜야 할 핵심 동작은 `계산한 값을 문자열에 삽입함`입니다. 목표는 같은 입력에 같은 결과를 내는 것으로, 각 언어의 규칙에 맞게 옮겼는지 실행 결과로 대조하세요.

| 언어   | 옮길 때 확인할 표현과 규칙 |
| ------ | -------------------------- |
| C17    | printf("%d분\n", minutes)  |
| Python | print(f"{minutes}분")      |
| Rust   | println!("{minutes}분")    |

C17에서는 `printf("%d분\n", minutes)` 규칙을 적용합니다. "`기초 1주차 회상과 오류 찾기`" 수업의 실행 결과(`30분`)를 기준으로 삼고, C는 범위와 널 검사를 자동으로 해 주지 않으므로, 코드에 사용된 접근마다 유효 범위를 직접 확인해야 합니다. Python에서는 `print(f"{minutes}분")` 규칙을 따릅니다. 실패나 빈 입력은 예외로 드러내며 조용히 넘기지 마세요. Rust에서는 `println!("{minutes}분")` 규칙을 따릅니다. 실행 결과가 다르면 컴파일 오류(타입, 소유권, 빌림)와 실행 때 패닉(인덱스 범위 등) 중 어느 쪽인지 메시지부터 구분하세요.

## 실습 순서

예측(`30분` 맞히기) → 빈칸(`f"` 채우기) → 변경(`처음 등장하는 숫자를 20에서 21로`) → 오류 수정(`문자열 앞 f를 빼고 {minutes}를 글자 그대로 출력함` 찾기) → 독립 구현(`'기초 1주차 회상과 오류 찾기' 개념을 보여주는 작은 프로그램` 만들기) 순으로 진행하세요. 각 단계의 답은 본문의 `30분` 및 `f"` 설명과 대조하세요.
