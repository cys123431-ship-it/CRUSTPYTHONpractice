## 오늘 배울 이유

프로그램은 입력을 받아 계산하고 결과를 출력해야 쓸모가 있습니다. 처음에는 입력을 변수에 고정해 흐름을 확인합니다. Day 02 "`출력과 입력값의 흐름`"에서는 Python 코드의 실행 결과(`안녕, 요섭`)를 따라가며, `입력값을 읽어 출력함` 동작이 왜 필요한지 확인합니다. 이 동작이 빠지면 "`변수 이름을 따옴표로 감싸 값 대신 글자 name을 출력함`" 같은 문제가 생깁니다.

## 시작 전에 확인할 것

바로 앞선 [Day 01](/learn/day-01-variables-types)에서 배운 "변수와 자료형 — 값에 이름을 붙이고 사용하는 법" 내용을 한 문장으로 말해 보세요. 이번 "`출력과 입력값의 흐름`"에서 새로 달라지는 조건을 찾아보세요. 핵심 표현은 `name`입니다.

## 머릿속 그림

입력 name은 상자 속 글자이고 print는 그 상자에 적힌 값을 읽어 화면에 보냅니다. Day 02에서는 아래 흐름 순서대로 상태가 바뀌고, 결과를 가르는 부분은 `name`입니다.

```text
name="요섭"  →  print가 name을 읽음  →  안녕, 요섭
```

위 흐름에서 `name` 부분이 실행되는 지점을 찾으면 읽는 값과 바뀌는 값이 나뉘어 보입니다. 마지막 출력은 `안녕, 요섭`입니다.

## 천천히 풀어보기

`name = "요섭"`은 사용자 입력을 아직 받지 않고 연습용 입력을 미리 정해 둔 것입니다. 변수 `name`에는 글자 요섭이 들어가고, `print("안녕,", name)`은 두 값을 차례로 읽어 화면에 보냅니다. 쉼표로 분리된 인수 사이에는 `print`가 공백을 넣으므로 결과는 `안녕, 요섭`입니다. `print("name")`으로 바꾸면 따옴표 속 글자 그대로 `name`이 나옵니다. 변수의 **이름**과 변수에 들어 있는 **값**을 구별해 보세요.

실제 입력을 받으려면 `name = input("이름: ")`처럼 바꿀 수 있습니다. `input`은 입력한 글자를 문자열로 돌려줍니다. 아무것도 입력하지 않고 엔터를 누르면 빈 문자열이 들어오므로, 입력이 비었을 때 어떤 인사말을 보여 줄지도 직접 정해 보세요.

## 문법을 예제로 보기

아래 Python 코드는 Day 02 "`출력과 입력값의 흐름`"의 독립 예제입니다. 전체 2줄 가운데 핵심 부분은 `name`이며, 실행 결과는 `안녕, 요섭`입니다.

```python
name = "요섭"
print("안녕,", name)
```

예상 출력:

```text
안녕, 요섭
```

하단 Python 실행 영역에 같은 코드가 들어 있습니다. 먼저 실행 결과(`안녕, 요섭`)를 가리고 예측한 뒤 실행해 비교하세요.

## 핵심 줄 따라 읽기

예제의 핵심 표현은 `name`입니다. 아래 줄 번호가 붙은 코드에서 이 표현이 있는 줄을 찾으세요.

```python
 1 | name = "요섭"
 2 | print("안녕,", name)
```

1. name에 문자열을 저장합니다
2. print의 두 인수를 차례로 평가합니다
3. 쉼표 사이 공백을 넣어 한 줄로 출력합니다

`name` 부분이 실행될 때 읽는 값과 바뀌는 값을 한 줄씩 적어 보세요. 다음 `결과 예측과 작은 변경`에서는 이 부분이 달라집니다.

## 실행 추적

| 순서 | 상태 또는 동작      |
| ---: | ------------------- |
|    1 | name="요섭"         |
|    2 | print가 name을 읽음 |
|    3 | 안녕, 요섭          |

위 순서대로 실행한 최종 출력은 `안녕, 요섭`입니다. `name="요섭"` 단계와 마지막 단계를 비교하면 입력과 출력의 관계가 보입니다.

## 다른 예제로 다시 이해하기

이번에는 이름이 비어 있을 때를 보세요. `name = ""`이고 `print("안녕,", name)`이면 빈 이름 자리까지 공백이 붙습니다. 입력을 그대로 쓰는 앱이라면 빈 문자열 검사를 먼저 해 `name = name or "익명"`으로 바꿀 수 있습니다. 그러면 출력은 `안녕, 익명`입니다. **입력을 정한다 → 필요한 경우 고친다 → 출력한다**라는 순서를 익혀 보세요.

## 결과 예측과 작은 변경

원본 실행 결과는 `안녕, 요섭`입니다. 아래 코드에서 원본과 다른 줄을 먼저 찾으세요.

```python
name = "요섭!"
print("안녕,", name)
```

찾은 줄을 적용했을 때의 실행 결과를 먼저 예측해 보세요.

해설: 바뀐 코드의 실행 결과는 아래와 같습니다.

```text
안녕, 요섭!
```

원본(`안녕, 요섭`)과 달라졌습니다. 다른 줄(`name = "요섭"` → `name = "요섭!"`)에서 시작된 차이가 이후 흐름을 타고 최종 출력에 반영되었습니다. 원본 추적(`name="요섭"` → …)과 바뀐 줄부터 대조해 보세요.

## 자주 틀리는 지점

**확인할 실수: 변수 이름을 따옴표로 감싸 값 대신 글자 name을 출력함.** 정상 코드의 실행 결과는 `안녕, 요섭`입니다.

- 정상 줄: `name = "요섭"`
- 잘못된 줄: `"익명" = "요섭"`

두 줄을 나란히 놓고 `입력 name은 상자 속 글자이고 print는 그 상자에 적힌 값을 읽어 화면에 보냅니다.` 기준으로 어느 쪽이 맞는지 설명하세요. 결과가 예상과 다르면 `name="요섭"`부터 `안녕, 요섭`까지 처음 어긋난 곳을 찾습니다.

## 다른 언어로 옮기기

세 언어에서 지켜야 할 핵심 동작은 `입력값을 읽어 출력함`입니다. 목표는 같은 입력에 같은 결과를 내는 것으로, 각 언어의 규칙에 맞게 옮겼는지 실행 결과로 대조하세요.

| 언어   | 옮길 때 확인할 표현과 규칙         |
| ------ | ---------------------------------- |
| C17    | char 배열과 printf의 %s 형식 사용  |
| Python | print의 인수 사이에 기본 공백 삽입 |
| Rust   | println!의 {} 자리에 값 전달       |

C17에서는 `char 배열과 printf의 %s 형식 사용` 규칙을 적용합니다. "`출력과 입력값의 흐름`" 수업의 실행 결과(`안녕, 요섭`)를 기준으로 삼고, C는 범위와 널 검사를 자동으로 해 주지 않으므로, 코드에 사용된 접근마다 유효 범위를 직접 확인해야 합니다. Python에서는 `print의 인수 사이에 기본 공백 삽입` 규칙을 따릅니다. 실패나 빈 입력은 예외로 드러내며 조용히 넘기지 마세요. Rust에서는 `println!의 {} 자리에 값 전달` 규칙을 따릅니다. 실행 결과가 다르면 컴파일 오류(타입, 소유권, 빌림)와 실행 때 패닉(인덱스 범위 등) 중 어느 쪽인지 메시지부터 구분하세요.

## 실습 순서

예측(`안녕, 요섭` 맞히기) → 빈칸(`name` 채우기) → 변경(`첫 문자열을 '요섭'에서 '요섭!'로`) → 오류 수정(`변수 이름을 따옴표로 감싸 값 대신 글자 name을 출력함` 찾기) → 독립 구현(`출력과 입력값의 흐름을 보여 주는` 만들기) 순으로 진행하세요. 각 단계의 답은 본문의 `안녕, 요섭` 및 `name` 설명과 대조하세요.
