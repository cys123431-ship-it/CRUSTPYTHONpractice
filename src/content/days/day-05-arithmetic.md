## 1. 오늘 배울 내용

지금까지 `+`와 `/` 정도만 썼습니다. 오늘은 계산에 쓰는 **산술 연산자**를 모두 정리하고, 식이 **어떤 순서로** 계산되는지 배웁니다.

1. 세 언어의 산술 연산자를 표로 정리합니다.
   - 공통: `+`, `-`, `*`, `/`, `%`
   - Python: `//`, `**`
   - C: `pow`
   - Rust: `.pow()`, `.powf()`
2. **우선순위**(무엇을 먼저 계산하나)와 **결합 방향**(같은 순위면 어느 쪽부터 계산하나)을 익힙니다.
3. 식을 **트리**로 그려 계산 순서를 눈으로 확인합니다.
4. **음수의 몫과 나머지**가 Python과 C·Rust에서 다른 이유를 봅니다.
5. `0.1 + 0.2`가 `0.3`이 아닌 이유를 알아봅니다.
6. 몫과 나머지로 **시간 변환**과 **거스름돈**을 계산합니다.

## 2. 왜 필요한가

계산식의 작은 순서 차이가 결과를 완전히 바꿉니다. 세 점수의 평균을 `a + b + c / 3`이라고 쓰면, 사람 눈에는 "합을 3으로 나눈다"로 보이지만 컴퓨터는 `c / 3`을 먼저 계산합니다. 이런 실수는 오류 메시지도 없이 **틀린 답**을 내기 때문에 더 위험합니다.

몫과 나머지는 생각보다 자주 씁니다.

- 초를 분과 초로 나누기(`125초 = 2분 5초`)
- 짝수·홀수 판별(`n % 2`)
- 거스름돈의 지폐 장수 세기
- 칸 번호를 격자의 행과 열로 바꾸기(`행 = 번호 / 열수`, `열 = 번호 % 열수`)

## 3. 그림으로 이해하기

컴퓨터는 식을 **트리**로 바꿔서, 아래(잎)부터 위(뿌리)로 계산합니다. `2 + 3 * 4`와 `(2 + 3) * 4`를 비교해 봅시다.

```text
    2 + 3 * 4                (2 + 3) * 4

        +                         *
       / \                       / \
      2   *                     +   4
         / \                   / \
        3   4                 2   3

  3 * 4 = 12 먼저            2 + 3 = 5 먼저
  2 + 12 = 14                5 * 4 = 20
```

우선순위가 높은 연산자일수록 트리의 **아래쪽**에 놓여 먼저 계산됩니다. 괄호는 "이 부분을 한 덩어리로 먼저 계산하라"는 표시라서, 괄호 안이 아래로 내려갑니다.

## 4. 천천히 풀어보기

### 4.1 산술 연산자

| 뜻           | Python   | C                    | Rust                      | `17`과 `5`로 계산 |
| ------------ | -------- | -------------------- | ------------------------- | ----------------- |
| 더하기       | `a + b`  | `a + b`              | `a + b`                   | 22                |
| 빼기         | `a - b`  | `a - b`              | `a - b`                   | 12                |
| 곱하기       | `a * b`  | `a * b`              | `a * b`                   | 85                |
| 나누기(실수) | `a / b`  | `(double)a / b`      | `a as f64 / b as f64`     | 3.4               |
| 몫(정수)     | `a // b` | `a / b` (정수끼리)   | `a / b` (정수끼리)        | 3                 |
| 나머지       | `a % b`  | `a % b`              | `a % b`                   | 2                 |
| 거듭제곱     | `a ** 2` | `pow(a, 2)` (double) | `a.pow(2)`, `x.powf(0.5)` | 289               |

Python만 **실수 나눗셈 `/`** 과 **몫 `//`** 을 다른 기호로 씁니다. C와 Rust의 `/`는 **값의 자료형**에 따라 다르게 동작합니다. 정수끼리면 몫, 실수가 섞이면 실수 나눗셈입니다. Rust에서 `//`는 주석이라 몫 연산자로 쓸 수 없습니다.

### 4.2 우선순위와 결합 방향

위에 있을수록 먼저 계산됩니다.

| 순위 | 연산자              | 같은 순위일 때 |
| ---: | ------------------- | -------------- |
|    1 | 괄호 `( )`          | 안쪽부터       |
|    2 | Python `**`         | **오른쪽부터** |
|    3 | 부호 `-x`           | (한 개만 붙음) |
|    4 | `*`, `/`, `//`, `%` | 왼쪽부터       |
|    5 | `+`, `-`            | 왼쪽부터       |

"왼쪽부터"라는 규칙 때문에 `100 / 10 / 2`는 `(100 / 10) / 2 = 5`입니다. `100 / (10 / 2) = 20`이 아닙니다. Python의 `**`만 예외로 오른쪽부터 계산해서 `2 ** 3 ** 2 = 2 ** 9 = 512`입니다. 또 `**`가 부호보다 먼저라서 `-2 ** 2`는 `-(2 ** 2) = -4`입니다. 헷갈리면 **괄호를 쓰세요**. 괄호는 계산 결과를 바꾸지 않을 때도 읽는 사람에게 의도를 알려 줍니다.

### 4.3 음수의 몫과 나머지

`-7 ÷ 2 = -3.5`입니다. 이것을 정수로 만드는 방법이 두 가지입니다.

```text
          -4        -3.5      -3                    0
  ─────────●─────────┼─────────●────────────────────●────▶
           ↑                   ↑
     Python: 내림            C·Rust: 0 쪽으로 버림
     (더 작은 쪽)
```

어느 쪽이든 **몫 × 나누는 수 + 나머지 = 원래 수**가 되도록 나머지가 정해집니다.

| 언어    |    `-7 / 2` 몫 | 나머지 | 확인                 |
| ------- | -------------: | -----: | -------------------- |
| Python  | `-7 // 2 = -4` |    `1` | `-4 × 2 + 1 = -7`    |
| C, Rust |  `-7 / 2 = -3` |   `-1` | `-3 × 2 + (-1) = -7` |

Python의 나머지는 **나누는 수와 부호가 같고**, C와 Rust의 나머지는 **나누어지는 수와 부호가 같습니다**. 양수끼리 계산할 때는 차이가 없습니다. 음수를 다룰 때 Python처럼 "항상 0 이상인 나머지"가 필요하면 Rust는 `rem_euclid`, C는 `((a % b) + b) % b`를 씁니다.

### 4.4 실수의 오차

컴퓨터는 실수를 **2진수**로 저장합니다. 10진수에서 1/3이 `0.333...`으로 끝없이 이어지듯, 10진수 `0.1`은 2진수로 끝없이 이어져서 **가장 가까운 값**으로 잘라 저장합니다. 그래서 `0.1 + 0.2`는 `0.30000000000000004`가 됩니다. 이것은 버그가 아니라 세 언어 모두 같은 표준(IEEE 754)을 따르기 때문입니다. 대처 방법은 다음과 같습니다.

- 출력할 때 자릿수를 정합니다(`{x:.2f}`, `%.2f`, `{x:.2}`).
- 두 실수가 같은지 `==`로 비교하지 말고, 차이가 아주 작은지 비교합니다(Day 12).
- 돈처럼 정확해야 하는 값은 원 단위 **정수**로 계산합니다.

## 5. C로 구현하기

C의 수학 함수(`pow`, `sqrt`)는 `math.h`에 있고, 컴파일할 때 수학 라이브러리를 연결하는 `-lm` 옵션이 필요할 수 있습니다.

```c
// 파일: arithmetic.c
#include <stdio.h>
#include <math.h>                        // pow, sqrt 같은 수학 함수

int main(void) {
    int a = 17, b = 5;
    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    printf("a / b = %d\n", a / b);        // 정수끼리: 몫
    printf("a %% b = %d\n", a % b);       // 나머지
    printf("(double)a / b = %.1f\n", (double)a / b);
    printf("pow(a, 2) = %.0f\n", pow(a, 2));   // pow는 double을 돌려준다
    printf("sqrt(2) = %.4f\n", sqrt(2));

    printf("2 + 3 * 4 = %d\n", 2 + 3 * 4);
    printf("(2 + 3) * 4 = %d\n", (2 + 3) * 4);
    printf("100 / 10 / 2 = %d\n", 100 / 10 / 2);

    printf("-7 / 2 = %d, -7 %% 2 = %d\n", -7 / 2, -7 % 2);
    printf("0.1 + 0.2 = %.17f\n", 0.1 + 0.2);

    int x = 5;
    x++;                                  // x = x + 1
    printf("x++ 뒤 x = %d\n", x);

    int seconds = 3725;
    printf("%d초 = %d시간 %d분 %d초\n", seconds, seconds / 3600, seconds % 3600 / 60, seconds % 60);
    return 0;
}
```

실행 결과:

```text
a + b = 22
a - b = 12
a * b = 85
a / b = 3
a % b = 2
(double)a / b = 3.4
pow(a, 2) = 289
sqrt(2) = 1.4142
2 + 3 * 4 = 14
(2 + 3) * 4 = 20
100 / 10 / 2 = 5
-7 / 2 = -3, -7 % 2 = -1
0.1 + 0.2 = 0.30000000000000004
x++ 뒤 x = 6
3725초 = 1시간 2분 5초
```

| 코드                                 | 설명                                                                                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `#include <math.h>`                  | 수학 함수의 선언이 들어 있는 헤더입니다.                                                                                                   |
| `printf("a %% b = %d\n", a % b);`    | 서식 문자열 안의 `%%`는 글자 `%`, 식 `a % b`의 `%`는 나머지 연산자입니다. 같은 글자가 두 가지로 쓰이니 주의하세요.                         |
| `(double)a / b`                      | `a`를 먼저 실수로 바꿨기 때문에 실수 나눗셈 3.4가 됩니다. `(double)(a / b)`라고 쓰면 몫 3을 먼저 구한 뒤 바꾸므로 3.0이 됩니다.            |
| `pow(a, 2)`                          | `double` 결과라 `%.0f`로 소수점 없이 출력했습니다. 정수 제곱은 `a * a`가 더 빠르고 정확합니다.                                             |
| `printf("0.1 + 0.2 = %.17f\n", ...)` | 소수점 아래 17자리까지 보면 저장된 값의 오차가 드러납니다.                                                                                 |
| `x++;`                               | `x = x + 1`의 줄임입니다. C에만 있는 **증가 연산자**입니다. `x--`는 1 감소입니다. 식 안에 섞어 쓰면 헷갈리므로 이렇게 한 줄에 따로 쓰세요. |
| `seconds % 3600 / 60`                | `%`와 `/`는 같은 순위라 왼쪽부터 계산합니다. 시간을 떼어 낸 나머지 125초를 60으로 나눠 2분입니다.                                          |

## 7. Rust로 구현하기

Rust는 **정수와 실수를 섞어 계산하는 것을 허용하지 않습니다**. `17 / 5.0`은 컴파일 오류이고, 반드시 `as f64`로 자료형을 맞춰야 합니다. 거듭제곱과 제곱근은 연산자가 아니라 **메서드**입니다.

```rust
// 파일: arithmetic.rs
fn main() {
    let (a, b): (i32, i32) = (17, 5);
    println!("a + b = {}, a - b = {}, a * b = {}", a + b, a - b, a * b);
    println!("a / b = {}, a % b = {}", a / b, a % b);
    println!("a as f64 / b as f64 = {}", a as f64 / b as f64);
    println!("a.pow(2) = {}", a.pow(2));          // 정수 거듭제곱
    println!("2.0_f64.sqrt() = {:.4}", 2.0_f64.sqrt());
    println!("2.0_f64.powf(0.5) = {:.4}", 2.0_f64.powf(0.5));

    println!("2 + 3 * 4 = {}", 2 + 3 * 4);
    println!("(2 + 3) * 4 = {}", (2 + 3) * 4);

    println!("-7 / 2 = {}, -7 % 2 = {}", -7 / 2, -7 % 2);
    // Python처럼 '내림 몫'과 '항상 0 이상인 나머지'가 필요할 때
    println!("div_euclid = {}, rem_euclid = {}", (-7_i32).div_euclid(2), (-7_i32).rem_euclid(2));

    println!("0.1 + 0.2 = {}", 0.1 + 0.2);
    println!("(-5_i32).abs() = {}", (-5_i32).abs());

    let seconds = 3725;
    println!("{seconds}초 = {}시간 {}분 {}초", seconds / 3600, seconds % 3600 / 60, seconds % 60);
}
```

실행 결과:

```text
a + b = 22, a - b = 12, a * b = 85
a / b = 3, a % b = 2
a as f64 / b as f64 = 3.4
a.pow(2) = 289
2.0_f64.sqrt() = 1.4142
2.0_f64.powf(0.5) = 1.4142
2 + 3 * 4 = 14
(2 + 3) * 4 = 20
-7 / 2 = -3, -7 % 2 = -1
div_euclid = -4, rem_euclid = 1
0.1 + 0.2 = 0.30000000000000004
(-5_i32).abs() = 5
3725초 = 1시간 2분 5초
```

### 코드 한 부분씩 읽기

| 코드                                | 설명                                                                                                                                       |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `let (a, b): (i32, i32) = (17, 5);` | 메서드(`a.pow`)를 부르려면 자료형이 정해져 있어야 해서 `i32`라고 적었습니다. 적지 않으면 "어떤 정수인지 모른다"는 오류가 납니다.           |
| `a.pow(2)`                          | 정수 거듭제곱입니다. 지수는 `u32`여야 합니다.                                                                                              |
| `2.0_f64.sqrt()`, `.powf(0.5)`      | 실수 메서드입니다. `2.0_f64`의 `_f64`는 "이 숫자는 f64"라는 표시이고, `_`는 읽기 좋게 넣는 구분자입니다(`1_000_000`처럼).                  |
| `-7 / 2`, `-7 % 2`                  | C와 같이 0 쪽으로 버려 -3, 나머지 -1입니다.                                                                                                |
| `(-7_i32).div_euclid(2)`            | Python의 `//`처럼 내림 몫 -4입니다. `rem_euclid`는 항상 0 이상인 나머지 1입니다. 괄호가 없으면 `-(7.div_euclid(2))`로 계산되니 주의하세요. |
| `(-5_i32).abs()`                    | 절댓값입니다. C는 `abs(-5)`(stdlib.h), Python은 `abs(-5)`입니다.                                                                           |

## 8. 실행 추적

`seconds % 3600 / 60`과 `a + b + c / 3`을 트리 없이 **한 단계씩** 계산해 봅니다. 매 단계에서 가장 먼저 계산할 부분에 밑줄(`‾‾`)을 쳤다고 생각하세요.

| 단계 | `3725 % 3600 / 60`    | `80 + 90 + 70 / 3` (C 정수) |
| ---: | --------------------- | --------------------------- |
|    1 | `3725 % 3600` → `125` | `70 / 3` → `23`             |
|    2 | `125 / 60` → `2`      | `80 + 90` → `170`           |
|    3 |                       | `170 + 23` → `193`          |
| 결과 | `2` (분)              | `193` (평균이 아님!)        |

오른쪽 식은 곱셈·나눗셈 순위 때문에 `70 / 3`이 가장 먼저 계산됩니다. 실습의 디버그 문제가 이 버그입니다.

## 9. 다른 예제로 다시 이해하기

편의점에서 62,350원어치를 사고 10만 원을 냈습니다. 거스름돈 37,650원을 만 원, 천 원, 백 원, 십 원 단위로 나눠 봅시다. **큰 단위부터 몫으로 개수를 구하고, 나머지를 다음 단위로 넘기는** 것이 핵심입니다.

```python
# 파일: change.py
change = 100000 - 62350
print(f"거스름돈: {change}원")

man = change // 10000        # 만 원짜리 개수
change %= 10000              # change = change % 10000, 남은 돈
cheon = change // 1000
change %= 1000
baek = change // 100
change %= 100
sip = change // 10

print(f"만 원 {man}장, 천 원 {cheon}장, 백 원 {baek}개, 십 원 {sip}개")
print("확인:", man * 10000 + cheon * 1000 + baek * 100 + sip * 10)
```

실행 결과:

```text
거스름돈: 37650원
만 원 3장, 천 원 7장, 백 원 6개, 십 원 5개
확인: 37650
```

같은 계산을 C로 하면서, 몫과 나머지가 **격자의 행과 열**로도 쓰인다는 것을 함께 봅시다. 칸이 한 줄에 4개씩 있는 달력에서 0번부터 시작하는 칸 번호 `n`은 `n / 4`번째 줄, `n % 4`번째 칸입니다.

```c
// 파일: change.c
#include <stdio.h>

int main(void) {
    int change = 100000 - 62350;
    int man = change / 10000;
    change %= 10000;
    int cheon = change / 1000;
    change %= 1000;
    int baek = change / 100;
    change %= 100;
    int sip = change / 10;
    printf("만 원 %d장, 천 원 %d장, 백 원 %d개, 십 원 %d개\n", man, cheon, baek, sip);

    int n = 13;
    printf("13번 칸은 %d번째 줄 %d번째 칸 (한 줄에 4칸, 0부터)\n", n / 4, n % 4);
    printf("13은 %s\n", n % 2 == 0 ? "짝수" : "홀수");
    return 0;
}
```

실행 결과:

```text
만 원 3장, 천 원 7장, 백 원 6개, 십 원 5개
13번 칸은 3번째 줄 1번째 칸 (한 줄에 4칸, 0부터)
13은 홀수
```

`n % 2 == 0`은 "2로 나눈 나머지가 0인가", 즉 짝수인지 묻는 식입니다. 비교 연산자 `==`는 Day 12에서, `? :`는 Day 13에서 배웁니다.

## 10. 연산 결과의 자료형

| 식           | Python   | C                    | Rust                |
| ------------ | -------- | -------------------- | ------------------- |
| 정수 + 정수  | 정수     | `int`                | 같은 정수 자료형    |
| 정수 / 정수  | **실수** | `int` (몫)           | 정수 (몫)           |
| 정수 + 실수  | 실수     | `double` (자동 변환) | **컴파일 오류**     |
| 정수 // 정수 | 정수     | (없음)               | (없음, `//`는 주석) |
| 실수 % 실수  | 실수     | `fmod(a, b)` 사용    | 실수                |

C는 자료형이 다르면 **넓은 쪽으로 자동 변환**합니다(`int` + `double` → `double`). 편리하지만 의도하지 않은 변환이 숨어 들어올 수 있어서, Rust는 모든 변환을 `as`로 적게 합니다. 자세한 규칙은 Day 6에서 다룹니다.

```rust
// 파일: zero_div.rs (실행 오류: attempt to divide by zero)
fn main() {
    let total = 100;
    let count: i32 = "0".parse().unwrap();
    println!("{}", total / count);
}
```

Python과 Rust는 0으로 나누면 멈춥니다. C에서 정수를 0으로 나누는 것은 **정의되지 않은 동작**이라 프로그램이 갑자기 죽거나 이상한 값이 나옵니다. 나누기 전에 0인지 확인하세요(Day 13). 참고로 실수 `1.0 / 0.0`은 세 언어 모두 무한대(`inf`)가 됩니다(Python은 예외).

### 실수 2: Rust에서 정수와 실수를 섞는다

```rust
// 파일: mixed.rs (컴파일 오류: E0277)
fn main() {
    let minutes = 90;
    let hours = minutes / 60.0;
    println!("{hours}");
}
```

`cannot divide {integer} by {float}`라는 오류가 납니다. `minutes as f64 / 60.0`으로 고칩니다.

### 실수 3: Python의 //를 다른 언어에서 쓴다

Rust와 C에서 `//`는 **주석의 시작**입니다. `let m = 125 // 60;`은 `let m = 125`까지만 남아 세미콜론이 없다는 오류가 납니다.

### 실수 4: 평균을 정수 나눗셈으로 구한다

`(80 + 85) / 2`는 C와 Rust에서 `82`입니다(정확히는 82.5). 실수 평균이 필요하면 `/ 2.0`(C) 또는 `as f64 / 2.0`(Rust)으로 나눕니다.

### 실수 5: 실수를 ==로 비교한다

```python
# 파일: float_eq.py
print(0.1 + 0.2 == 0.3)
print(abs((0.1 + 0.2) - 0.3) < 1e-9)
```

실행 결과:

```text
False
True
```

두 값의 차이가 아주 작은 수(`1e-9` = 0.000000001)보다 작은지로 비교합니다.

## 13. Q&A

**Q. 우선순위 표를 다 외워야 하나요?**

A. "괄호 → 거듭제곱 → 곱셈·나눗셈·나머지 → 덧셈·뺄셈, 같은 순위는 왼쪽부터" 정도만 기억하세요. 나머지는 **헷갈리면 괄호**로 해결하면 됩니다. 괄호를 넣는다고 느려지지 않습니다.

**Q. 나머지 연산자는 실수에도 쓸 수 있나요?**

A. Python과 Rust는 `7.5 % 2`처럼 실수에도 `%`를 쓸 수 있습니다(1.5). C의 `%`는 정수 전용이고, 실수는 `fmod(7.5, 2)`를 씁니다.

**Q. `x++`와 `++x`는 무엇이 다른가요? (C)**

A. 둘 다 x를 1 늘리지만, 식 안에서 쓸 때 **돌려주는 값**이 다릅니다. `x++`는 늘리기 **전** 값, `++x`는 늘린 **후** 값입니다. `y = x++ + ++x;`처럼 한 식에서 같은 변수를 여러 번 바꾸면 결과가 정해지지 않으니, 항상 한 줄에 하나만 따로 쓰세요. Python과 Rust가 `++`를 없앤 이유이기도 합니다.

**Q. 돈 계산은 왜 정수로 하나요?**

A. `0.1 + 0.2`의 오차가 계속 쌓이면 1원이 어긋날 수 있기 때문입니다. 원 단위(센트 단위) 정수로 계산하고, 출력할 때만 단위를 붙입니다. Python에는 10진수로 정확하게 계산하는 `decimal` 모듈도 있습니다.

## 14. 핵심 요약

- 공통 연산자는 `+ - * / %`입니다. Python은 실수 나눗셈 `/`와 몫 `//`를 구분하고 거듭제곱 `**`가 있습니다. C는 `pow`(double), Rust는 `.pow()`와 `.powf()`를 씁니다.
- C와 Rust에서 **정수끼리** `/`는 몫입니다. 실수 결과가 필요하면 한쪽을 먼저 실수로 바꿉니다.
- 우선순위: 괄호 → `**` → 곱셈·나눗셈·나머지 → 덧셈·뺄셈. 같은 순위는 왼쪽부터, Python `**`만 오른쪽부터 계산합니다.
- 음수 나눗셈: Python은 내림(`-7 // 2 = -4`, 나머지 1), C·Rust는 0 쪽으로 버림(`-3`, 나머지 -1). Rust는 `div_euclid`, `rem_euclid`로 Python처럼 계산할 수 있습니다.
- 실수는 2진수로 저장되어 작은 오차가 있습니다. 출력 자릿수를 정하고, `==` 대신 차이로 비교하고, 돈은 정수로 계산합니다.
- 몫과 나머지로 단위 변환(초 → 분), 거스름돈, 짝·홀 판별, 행·열 계산을 합니다.
