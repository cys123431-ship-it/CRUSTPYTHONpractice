## 오늘 배울 이유

학습 시간처럼 여러 수를 계산할 때 연산 순서를 틀리면 문법 오류 없이도 잘못된 결과가 나옵니다. Day 05 "`산술식과 연산 순서`"에서는 Python 코드의 실행 결과(`30`)를 따라가며, `연산자 우선순위대로 계산함` 동작이 왜 필요한지 확인합니다. 이 동작이 빠지면 "`왼쪽부터 20+5를 먼저 계산한다고 생각함`" 같은 문제가 생깁니다.

## 시작 전에 확인할 것

바로 앞선 [Day 04](/learn/day-04-rust-variables)에서 배운 "Rust의 let과 mut" 내용을 한 문장으로 말해 보세요. 이번 "`산술식과 연산 순서`"에서 새로 달라지는 조건을 찾아보세요. 핵심 표현은 `5 * 2`입니다.

## 머릿속 그림

곱셈을 먼저 끝낸 뒤 덧셈을 합니다. 원하는 순서가 다르면 괄호로 묶습니다. Day 05에서는 아래 흐름 순서대로 상태가 바뀌고, 결과를 가르는 부분은 `5 * 2`입니다.

```text
5*2=10  →  20+10=30  →  30 출력
```

위 흐름에서 `5 * 2` 부분이 실행되는 지점을 찾으면 읽는 값과 바뀌는 값이 나뉘어 보입니다. 마지막 출력은 `30`입니다.

## 천천히 풀어보기

`20 + 5 * 2`를 왼쪽부터 무조건 계산하면 50이라고 생각하기 쉽습니다. 실제 순서는 `5 * 2 = 10`, 이어서 `20 + 10 = 30`입니다. 곱셈·나눗셈은 덧셈·뺄셈보다 먼저 계산됩니다. ` (20 + 5) * 2`처럼 괄호를 쓰면 괄호 안 25를 먼저 만들어 50이 됩니다.

분 단위 비용이 기본 20에 추가 작업 5분씩 2회라고 생각해 보면 30이 자연스럽습니다. 괄호 하나만 달라져도 문제의 뜻이 달라질 수 있습니다. `20 + 5 * 3`은 몇 분인지 손으로 구한 뒤 실행 결과와 비교하세요.

## 문법을 예제로 보기

아래 Python 코드는 Day 05 "`산술식과 연산 순서`"의 독립 예제입니다. 전체 2줄 가운데 핵심 부분은 `5 * 2`이며, 실행 결과는 `30`입니다.

```python
minutes = 20 + 5 * 2
print(minutes)
```

예상 출력:

```text
30
```

하단 Python 실행 영역에 같은 코드가 들어 있습니다. 먼저 실행 결과(`30`)를 가리고 예측한 뒤 실행해 비교하세요.

## 핵심 줄 따라 읽기

예제의 핵심 표현은 `5 * 2`입니다. 아래 줄 번호가 붙은 코드에서 이 표현이 있는 줄을 찾으세요.

```python
 1 | minutes = 20 + 5 * 2
 2 | print(minutes)
```

1. 5 곱하기 2가 10이 됩니다
2. 20에 10을 더해 minutes에 저장합니다
3. print가 30을 출력합니다

`5 * 2` 부분이 실행될 때 읽는 값과 바뀌는 값을 한 줄씩 적어 보세요. 다음 `결과 예측과 작은 변경`에서는 이 부분이 달라집니다.

## 실행 추적

| 순서 | 상태 또는 동작 |
| ---: | -------------- |
|    1 | 5*2=10         |
|    2 | 20+10=30       |
|    3 | 30 출력        |

위 순서대로 실행한 최종 출력은 `30`입니다. `5*2=10` 단계와 마지막 단계를 비교하면 입력과 출력의 관계가 보입니다.

## 다른 예제로 다시 이해하기

`(8 + 4) / 2`는 괄호 안을 먼저 계산하므로 `12 / 2 = 6.0`입니다. `8 + 4 / 2`는 `4 / 2 = 2.0`부터 계산해 `10.0`입니다(Python의 `/`는 실수 결과). 괄호를 지우고 계산하면 단순히 쓰는 모양만 달라지는 것이 아니라 수식의 의미가 달라집니다. 손으로 계산 순서를 번호로 매겨 보세요.

## 결과 예측과 작은 변경

원본 실행 결과는 `30`입니다. 아래 코드에서 원본과 다른 줄을 먼저 찾으세요.

```python
minutes = 21 + 5 * 2
print(minutes)
```

찾은 줄을 적용했을 때의 실행 결과를 먼저 예측해 보세요.

해설: 바뀐 코드의 실행 결과는 아래와 같습니다.

```text
31
```

원본과 달라졌습니다. 원본 출력은 `30`입니다. 다른 줄(`minutes = 20 + 5 * 2` → `minutes = 21 + 5 * 2`)에서 시작된 차이가 이후 흐름을 타고 최종 출력에 반영되었습니다. 원본 추적(`5*2=10` → …)과 바뀐 줄부터 대조해 보세요.

## 자주 틀리는 지점

**확인할 실수: 왼쪽부터 20+5를 먼저 계산한다고 생각함.** 정상 코드의 실행 결과는 `30`입니다.

- 정상 줄: `minutes = 20 + 5 * 2`
- 잘못된 줄: `minutes = 20 + (20 + 5) * 2`

두 줄을 나란히 놓고 `곱셈을 먼저 끝낸 뒤 덧셈을 합니다. 원하는 순서가 다르면 괄호로 묶습니다.` 기준으로 어느 쪽이 맞는지 설명하세요. 결과가 예상과 다르면 `5*2=10`부터 `30`까지 처음 어긋난 곳을 찾습니다.

## 다른 언어로 옮기기

세 언어에서 지켜야 할 핵심 동작은 `연산자 우선순위대로 계산함`입니다. 목표는 같은 입력에 같은 결과를 내는 것으로, 각 언어의 규칙에 맞게 옮겼는지 실행 결과로 대조하세요.

| 언어   | 옮길 때 확인할 표현과 규칙 |
| ------ | -------------------------- |
| C17    | int minutes = 20 + 5 * 2;  |
| Python | minutes = 20 + 5 * 2       |
| Rust   | let minutes = 20 + 5 * 2;  |

C17에서는 `int minutes = 20 + 5 * 2;` 규칙을 적용합니다. "`산술식과 연산 순서`" 수업의 실행 결과(`30`)를 기준으로 삼고, C는 범위와 널 검사를 자동으로 해 주지 않으므로, 코드에 사용된 접근마다 유효 범위를 직접 확인해야 합니다. Python에서는 `minutes = 20 + 5 * 2` 규칙을 따릅니다. 실패나 빈 입력은 예외로 드러내며 조용히 넘기지 마세요. Rust에서는 `let minutes = 20 + 5 * 2;` 규칙을 따릅니다. 실행 결과가 다르면 컴파일 오류(타입, 소유권, 빌림)와 실행 때 패닉(인덱스 범위 등) 중 어느 쪽인지 메시지부터 구분하세요.

## 실습 순서

예측(`30` 맞히기) → 빈칸(`5 * 2` 채우기) → 변경(`처음 등장하는 숫자를 20에서 21로`) → 오류 수정(`왼쪽부터 20+5를 먼저 계산한다고 생각함` 찾기) → 독립 구현(`'산술식과 연산 순서' 개념을 보여주는 작은 프로그램` 만들기) 순으로 진행하세요. 각 단계의 답은 본문의 `30` 및 `5 * 2` 설명과 대조하세요.
