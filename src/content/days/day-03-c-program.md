## 1. 오늘 배울 내용

Day 1과 Day 2에서 C 프로그램을 몇 개 봤지만, 맨 위의 `#include`나 `int main(void)`는 "원래 이렇게 쓰는 것"으로 넘어갔습니다. 오늘은 그 뼈대의 의미와, 우리가 쓴 글자(소스 코드)가 **실행 파일**이 되는 과정을 배웁니다.

1. 소스 코드 → **전처리 → 컴파일 → 링크** → 실행 파일의 흐름.
2. C 프로그램의 뼈대를 이루는 요소:
   - 주석
   - `#include`
   - `main` 함수
   - 중괄호와 세미콜론
   - `return 0`
3. `printf`의 **서식 문자**를 하나씩 확인합니다.
   - 정수: `%d`, `%i`, `%u`
   - 진법: `%x`, `%X`, `%o`
   - 실수: `%f`, `%.2f`, `%e`, `%g`
   - 글자와 문자열: `%c`, `%s`
   - 퍼센트 기호: `%%`
4. 같은 뼈대와 형식 지정을 **Python**과 **Rust**로 옮깁니다.
5. **종료 코드**와 **표준 오류**로 "실패했다"를 알리는 방법을 봅니다.

## 2. 왜 필요한가

컴파일 오류를 처음 만나면 "어디가 틀렸는지"보다 "왜 이런 말을 하는지"를 모르는 경우가 많습니다. 소스 코드가 어떤 단계를 거치는지 알면 오류 메시지가 **어느 단계에서** 나왔는지 짐작할 수 있습니다.

| 오류 메시지 예                       | 나온 단계 | 뜻                                      |
| ------------------------------------ | --------- | --------------------------------------- |
| `stdio.h: No such file or directory` | 전처리    | 끼워 넣을 헤더 파일을 찾지 못함         |
| `expected ';' before 'printf'`       | 컴파일    | 문법이 맞지 않음                        |
| `undefined reference to 'prinft'`    | 링크      | 그런 이름의 함수 코드를 찾지 못함(오타) |

`printf`의 서식 문자는 앞으로 모든 C 수업에서 씁니다. 숫자를 16진수로 보거나 소수점 자리를 맞추는 일은 디버깅과 결과 확인에 늘 필요합니다.

## 3. 그림으로 이해하기

C 소스 파일 `first.c`가 실행되기까지의 과정입니다. `gcc first.c -o first`라는 명령 하나가 이 단계를 모두 해 줍니다.

```text
first.c (사람이 쓴 글)
   │  ① 전처리: #include 줄을 헤더 파일 내용으로 바꾸고, 주석을 지운다
   ▼
first.i (헤더가 끼워진 긴 C 코드)
   │  ② 컴파일: 문법을 검사하고 기계어로 번역한다
   ▼
first.o (기계어 조각, 아직 printf의 실제 코드는 없음)
   │  ③ 링크: 표준 라이브러리에 있는 printf 코드와 연결한다
   ▼
first.exe (실행 파일) ──▶ 실행 ──▶ 출력 + 종료 코드
```

Python은 이 과정이 다릅니다. `python first.py`를 실행하면 Python이 소스를 **그때그때 번역하며 실행**합니다(인터프리터). 그래서 따로 실행 파일이 생기지 않고, 문법 오류가 아닌 대부분의 오류는 **그 줄이 실행될 때** 발견됩니다. Rust는 C처럼 `rustc first.rs`로 컴파일해 실행 파일을 만듭니다. 큰 Rust 프로젝트는 `cargo build`, `cargo run`으로 컴파일과 실행을 관리합니다.

## 4. 천천히 풀어보기

### 4.1 C 프로그램의 뼈대

```c
#include <stdio.h>

int main(void) {
    printf("안녕하세요\n");
    return 0;
}
```

| 부분                 | 뜻                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `#include <stdio.h>` | 표준 입출력 헤더를 끼워 넣습니다. `printf`가 "문자열 하나와 값 여러 개를 받는 함수"라는 **선언**이 들어 있습니다.  |
| `int main(void)`     | 이름이 `main`인 **함수**를 정의합니다. `int`는 이 함수가 정수를 돌려준다는 뜻, `void`는 받는 값이 없다는 뜻입니다. |
| `{ ... }`            | 함수의 몸통입니다. 여기 있는 문장이 위에서 아래로 실행됩니다.                                                      |
| `printf(...);`       | 문장 하나입니다. C의 문장은 **세미콜론으로 끝납니다**. 줄바꿈은 문장의 끝이 아닙니다.                              |
| `return 0;`          | `main`을 끝내고 **종료 코드 0**을 운영체제에 돌려줍니다. 0은 "성공"이라는 약속입니다.                              |

주석은 두 가지입니다. `//`부터 줄 끝까지, 그리고 `/*`와 `*/` 사이입니다. 주석은 전처리 단계에서 지워지므로 실행 파일에는 영향이 없습니다.

### 4.2 printf의 서식 문자

`printf`의 첫 번째 인자는 **서식 문자열**이고, 그 안의 `%`로 시작하는 자리가 뒤의 값으로 바뀝니다.

| 서식       | 값의 자료형      | 출력 방식                            | 예: 값 → 출력                |
| ---------- | ---------------- | ------------------------------------ | ---------------------------- |
| `%d`, `%i` | `int`            | 10진수 정수                          | `42` → `42`                  |
| `%u`       | `unsigned int`   | 부호 없는 10진수                     | `42u` → `42`                 |
| `%x`, `%X` | `unsigned int`   | 16진수(소문자/대문자)                | `255` → `ff` / `FF`          |
| `%o`       | `unsigned int`   | 8진수                                | `8` → `10`                   |
| `%f`       | `double`         | 소수점 아래 6자리                    | `3.14159` → `3.141590`       |
| `%.2f`     | `double`         | 소수점 아래 2자리(반올림)            | `3.14159` → `3.14`           |
| `%e`       | `double`         | 지수 표기(× 10의 거듭제곱)           | `12345.678` → `1.234568e+04` |
| `%g`       | `double`         | `%f`와 `%e` 중 짧은 쪽, 유효숫자 6개 | `12345.678` → `12345.7`      |
| `%c`       | `int`(글자 번호) | 글자 하나                            | `'A'` 또는 `65` → `A`        |
| `%s`       | 문자열           | 문자열                               | `"hello"` → `hello`          |
| `%%`       | (값 없음)        | 퍼센트 기호                          | → `%`                        |

`1.234568e+04`는 1.234568 × 10⁴라는 뜻입니다. 아주 크거나 작은 수를 짧게 쓸 때 씁니다. **서식과 값의 자료형이 맞지 않으면** 엉뚱한 값이 출력됩니다. 컴파일할 때 `-Wall`을 켜면 이런 불일치를 경고로 알려 줍니다.

### 4.3 글자는 번호다

`%c`에 `65`를 주면 `A`가 출력됩니다. 컴퓨터는 글자를 **번호**로 저장하고, 영문자와 숫자, 기호의 번호는 **ASCII** 표로 정해져 있습니다. `'A'`는 65, `'a'`는 97, `'0'`은 48입니다. C에서 `'A'`는 사실 정수 65와 같은 값입니다. Python은 `ord("A")`로 번호를, `chr(65)`로 글자를 얻고, Rust는 `'A' as u32`와 `65u8 as char`로 바꿉니다. 한글처럼 ASCII 밖의 글자는 **유니코드** 번호를 쓰고, 파일에 저장할 때는 여러 바이트를 씁니다(Day 38).

### 4.4 종료 코드와 표준 오류

프로그램이 끝날 때 돌려주는 정수를 **종료 코드(exit code)** 라고 합니다. 화면에는 보이지 않지만, 명령을 이어서 실행하는 스크립트나 채점기는 이 값으로 성공과 실패를 구별합니다.

| 언어   | 성공으로 끝내기 | 실패로 끝내기                           | 오류 메시지 출력              |
| ------ | --------------- | --------------------------------------- | ----------------------------- |
| C      | `return 0;`     | `return 1;`                             | `fprintf(stderr, ...)`        |
| Python | 끝까지 실행     | `sys.exit(1)` 또는 `sys.exit("메시지")` | `print(..., file=sys.stderr)` |
| Rust   | `main`이 끝남   | `std::process::exit(1)`                 | `eprintln!(...)`              |

## 5. C로 구현하기

뼈대와 주석, 그리고 서식 문자를 모두 써 보는 프로그램입니다. 서식 문자 이름을 출력하려고 `%%d`처럼 퍼센트를 두 번 썼습니다.

```c
// 파일: first.c
/*
 * 여러 줄 주석: 컴파일러는 이 부분을 무시합니다.
 * 프로그램이 무엇을 하는지 사람에게 알려 주는 용도입니다.
 */
#include <stdio.h>                  // printf가 선언된 헤더 파일을 끼워 넣는다

int main(void) {                    // 프로그램은 항상 main에서 시작한다
    printf("안녕하세요, C!\n");

    int n = printf("printf returns bytes\n");
    printf("방금 줄은 %d바이트\n", n);   // printf는 출력한 바이트 수를 돌려준다

    printf("%%d  정수      : %d\n", 42);
    printf("%%i  정수      : %i\n", -7);
    printf("%%u  부호 없음 : %u\n", 42u);
    printf("%%x  16진수    : %x\n", 255);
    printf("%%X  16진수    : %X\n", 255);
    printf("%%o  8진수     : %o\n", 8);
    printf("%%f  실수      : %f\n", 3.14159);
    printf("%%.2f 소수 2자리: %.2f\n", 3.14159);
    printf("%%e  지수 표기 : %e\n", 12345.678);
    printf("%%g  짧은 표기 : %g\n", 12345.678);
    printf("%%c  글자      : %c\n", 'A');
    printf("%%c  65번 글자 : %c\n", 65);
    printf("%%s  문자열    : %s\n", "hello");
    printf("%%%%  퍼센트    : %%\n");
    return 0;                       // 0 = 정상 종료를 운영체제에 알린다
}
```

실행 결과:

```text

%d  정수      : 42
%i  정수      : -7
%u  부호 없음 : 42
%x  16진수    : ff
%X  16진수    : FF
%o  8진수     : 10
%f  실수      : 3.141590
%.2f 소수 2자리: 3.14
%e  지수 표기 : 1.234568e+04
%g  짧은 표기 : 12345.7
%c  글자      : A
%c  65번 글자 : A
%s  문자열    : hello
%%  퍼센트    : %
```

### 코드 한 부분씩 읽기

| 코드                                        | 설명                                                                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `/* ... */`                                 | 여러 줄 주석입니다. 가운데 줄의 `*`는 보기 좋게 맞춘 것일 뿐 규칙은 아닙니다.                                                        |
| `int n = printf("printf returns bytes\n");` | `printf`도 값을 돌려주는 함수입니다. 출력한 **바이트 수**(글자 20개 + 줄바꿈 1개 = 21)를 돌려줍니다. 대부분은 이 값을 버리고 씁니다. |
| `printf("%%d  정수      : %d\n", 42);`      | 앞의 `%%d`는 글자 `%d`를 출력하고, 뒤의 `%d`만 42로 바뀝니다.                                                                        |
| `42u`                                       | 숫자 뒤의 `u`는 "부호 없는(unsigned) 정수"라는 표시입니다. `%u`와 짝을 맞췄습니다.                                                   |
| `printf("%%c  65번 글자 : %c\n", 65);`      | 정수 65를 글자로 출력하면 `A`입니다.                                                                                                 |
| `printf("%%%%  퍼센트    : %%\n");`         | `%%%%`는 `%%` 두 글자를, 마지막 `%%`는 `%` 한 글자를 출력합니다.                                                                     |
| `return 0;`                                 | 종료 코드 0으로 끝납니다. `main`에서는 이 줄을 빠뜨려도 0이 돌아가도록 C 표준이 정해 두었지만, 뜻을 분명히 하려고 씁니다.            |

## 6. Python으로 구현하기

Python에는 `main`이 없어도 파일 맨 위부터 실행됩니다. 그래도 큰 프로그램에서는 C처럼 `main` 함수를 두고 마지막에 부르는 모양을 많이 씁니다. f-string의 `:` 뒤에 쓰는 형식 지정은 `printf`의 서식 문자와 거의 같습니다.

```python
# 파일: first.py
"""첫 Python 프로그램. 맨 위의 이 문자열은 모듈 설명(docstring)입니다."""
import sys


def main():
    print("안녕하세요, Python!")
    # f-string의 형식 지정: printf의 서식 문자와 거의 같다
    print(f"d:{42:d} x:{255:x} X:{255:X} o:{8:o} b:{5:b}")
    print(f"f:{3.14159:f} .2f:{3.14159:.2f} e:{12345.678:e} g:{12345.678:g}")
    print("%%-서식: %d %x %.2f %s" % (42, 255, 3.14159, "hello"))   # 옛 방식(C와 같은 서식)
    print(chr(65), ord("A"))        # 번호 → 글자, 글자 → 번호
    text = "printf returns bytes\n"
    print(len(text), "글자")
    return 0                        # C의 return 0과 같은 뜻


if __name__ == "__main__":          # 이 파일을 직접 실행했을 때만 main()을 부른다
    sys.exit(main())
```

실행 결과:

```text
안녕하세요, Python!
d:42 x:ff X:FF o:10 b:101
f:3.141590 .2f:3.14 e:1.234568e+04 g:12345.7
%-서식: 42 ff 3.14 hello
A 65
21 글자
```

### 코드 한 부분씩 읽기

| 코드                               | 설명                                                                                                                                      |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `"""첫 Python 프로그램..."""`      | 파일 맨 위의 문자열은 **docstring**이라는 설명문입니다. 주석(`#`)과 달리 프로그램 안에서 읽을 수도 있습니다.                              |
| `import sys`                       | C의 `#include`처럼 다른 모듈의 기능을 가져옵니다. 다만 Python은 실행 중에 모듈을 불러옵니다.                                              |
| `def main():`                      | `main`이라는 **함수**를 정의합니다. 안쪽 줄은 들여쓰기로 구분합니다. C의 중괄호 역할을 들여쓰기가 합니다.                                 |
| `{42:d}`, `{255:x}`, `{5:b}`       | 10진수, 16진수, 2진수입니다. 2진수 `b`는 C의 `printf`에는 없는 기능입니다.                                                                |
| `"%%-서식: %d %x %.2f %s" % (...)` | Python의 **옛 서식 방식**으로, C의 `printf`와 서식 문자가 같습니다. 오래된 코드에서 자주 보입니다. `%` 기호 자체는 `%%`로 씁니다.         |
| `chr(65)`, `ord("A")`              | 번호 → 글자, 글자 → 번호입니다.                                                                                                           |
| `len(text)`                        | 글자 수입니다. 영문과 줄바꿈만 있으니 C의 바이트 수와 같은 21입니다. 한글이 섞이면 둘이 달라집니다(Day 38).                               |
| `if __name__ == "__main__":`       | 이 파일을 **직접 실행하면** `__name__`이 `"__main__"`이 됩니다. 다른 파일에서 `import`하면 파일 이름이 되어 `main()`이 실행되지 않습니다. |
| `sys.exit(main())`                 | `main`이 돌려준 0을 종료 코드로 씁니다. C의 `return 0`과 같은 효과입니다.                                                                 |

## 7. Rust로 구현하기

Rust도 `fn main()`에서 시작합니다. `#include` 대신 `use`로 필요한 것을 가져오는데, `println!`처럼 자주 쓰는 것은 가져오지 않아도 쓸 수 있습니다.

```rust
// 파일: first.rs
//! 첫 Rust 프로그램. //!로 시작하는 줄은 파일(크레이트) 설명 주석입니다.

/// 세 줄짜리 문서 주석은 바로 아래 항목(여기서는 main)을 설명합니다.
fn main() {
    println!("안녕하세요, Rust!");
    println!("d:{} x:{:x} X:{:X} o:{:o} b:{:b}", 42, 255, 255, 8, 5);
    println!("f:{} .2:{:.2} e:{:e}", 3.14159, 3.14159, 12345.678);
    println!("Debug 형식: {:?} {:?}", "따옴표 포함", 'A');
    println!("{} {}", 'A' as u32, 65u8 as char);
    println!("중괄호 자체는 {{}}로 씁니다");
    let text = "printf returns bytes\n";
    println!("{} 바이트", text.len());
}
```

실행 결과:

```text
안녕하세요, Rust!
d:42 x:ff X:FF o:10 b:101
f:3.14159 .2:3.14 e:1.2345678e4
Debug 형식: "따옴표 포함" 'A'
65 A
중괄호 자체는 {}로 씁니다
21 바이트
```

### 코드 한 부분씩 읽기

| 코드                           | 설명                                                                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| `//!`, `///`                   | **문서 주석**입니다. `cargo doc` 명령이 이 주석으로 설명서를 만들어 줍니다. 일반 주석은 C와 같이 `//`와 `/* */`입니다.              |
| `fn main()`                    | `fn`은 함수를 정의하는 키워드입니다. C와 달리 돌려주는 자료형을 적지 않으면 "아무것도 돌려주지 않음"이고, 이때 종료 코드는 0입니다. |
| `{:x}`, `{:X}`, `{:o}`, `{:b}` | 진법 형식입니다. Python과 같은 글자를 씁니다.                                                                                       |
| `{}`에 `3.14159`               | Rust의 기본 실수 출력은 **필요한 자릿수만** 보여 줍니다. C의 `%f`처럼 6자리로 맞추지 않습니다.                                      |
| `{:e}` → `1.2345678e4`         | 지수 표기이지만 C와 모양이 다릅니다(자릿수를 줄이지 않고 `+04` 대신 `4`).                                                           |
| `{:?}`                         | **Debug 형식**입니다. 문자열은 따옴표까지, 글자는 작은따옴표까지 보여 줍니다.                                                       |
| `'A' as u32`, `65u8 as char`   | 글자를 번호로, 번호를 글자로 바꿉니다. `as char`는 0~255 범위인 `u8`에서만 쓸 수 있습니다.                                          |
| `{{}}`                         | 중괄호 자체를 출력합니다. `printf`의 `%%`와 같은 역할입니다.                                                                        |
| `text.len()`                   | 문자열의 **바이트 수**입니다.                                                                                                       |

## 8. 실행 추적

`printf("%d%% [%c%c]\n", 50, 'O', 75);`가 서식 문자열을 앞에서부터 읽으며 출력하는 과정입니다.

| 읽은 부분 | 종류   | 사용한 값 | 출력한 글자 | 지금까지의 출력 |
| --------- | ------ | --------- | ----------- | --------------- |
| `%d`      | 서식   | `50`      | `50`        | `50`            |
| `%%`      | 퍼센트 | 없음      | `%`         | `50%`           |
| ` [`      | 그대로 |           | ` [`        | `50% [`         |
| `%c`      | 서식   | `'O'`     | `O`         | `50% [O`        |
| `%c`      | 서식   | `75`      | `K`         | `50% [OK`       |
| `]\n`     | 그대로 |           | `]`, 줄바꿈 | `50% [OK]`      |

서식을 하나 만날 때마다 뒤의 값을 **하나씩 차례로** 씁니다. 값이 서식보다 적으면 없는 값을 읽으려 해서 쓰레기 값이 나오고, 많으면 남는 값은 무시됩니다. 둘 다 `-Wall`이 경고합니다.

## 9. 다른 예제로 다시 이해하기

웹 페이지의 색은 빨강·초록·파랑(RGB) 세기를 0~255로 정하고, `#FFA500`처럼 **16진수 두 자리씩** 붙여 씁니다. 주황색(255, 165, 0)을 세 언어로 색 코드로 바꿔 봅시다. `%02X`의 `02`는 "두 자리로 맞추되 빈자리는 0으로 채워라"라는 뜻입니다. 0을 `%X`로만 출력하면 `0` 한 글자가 되어 색 코드가 깨집니다.

```c
// 파일: color.c
#include <stdio.h>

int main(void) {
    int r = 255, g = 165, b = 0;
    printf("rgb(%d, %d, %d)\n", r, g, b);
    printf("잘못된 코드: #%X%X%X\n", r, g, b);
    printf("올바른 코드: #%02X%02X%02X\n", r, g, b);
    return 0;
}
```

실행 결과:

```text
rgb(255, 165, 0)
잘못된 코드: #FFA50
올바른 코드: #FFA500
```

Python은 형식 지정을 f-string 안에 쓰고, `int(글자, 16)`으로 거꾸로 16진수 글자를 정수로 바꿀 수 있습니다.

```python
# 파일: color.py
r, g, b = 255, 165, 0
code = f"#{r:02X}{g:02X}{b:02X}"
print(code)
print("A5를 10진수로:", int("A5", 16))
print("색 코드를 다시 나누기:", int(code[1:3], 16), int(code[3:5], 16), int(code[5:7], 16))
```

실행 결과:

```text
#FFA500
A5를 10진수로: 165
색 코드를 다시 나누기: 255 165 0
```

Rust도 같은 형식 지정을 쓰고, `u8::from_str_radix`로 16진수 글자를 바꿉니다. RGB 세기는 0~255이므로 `u8`(부호 없는 8비트 정수)이 딱 맞습니다.

```rust
// 파일: color.rs
fn main() {
    let (r, g, b): (u8, u8, u8) = (255, 165, 0);
    println!("#{r:02X}{g:02X}{b:02X}");
    let back = u8::from_str_radix("A5", 16).unwrap();
    println!("A5를 10진수로: {back}");
}
```

실행 결과:

```text
#FFA500
A5를 10진수로: 165
```

`code[1:3]`처럼 문자열의 일부를 잘라 내는 방법은 Day 27과 Day 36에서 배웁니다.

## 10. 종료 코드로 실패 알리기

정상 출력은 표준 출력으로, 오류 메시지는 **표준 오류**로 보내고 0이 아닌 종료 코드로 끝내는 것이 약속입니다. 아래 프로그램들은 "실패"하도록 만든 것이라 검증기도 실패(0이 아닌 종료 코드)와 오류 메시지를 확인합니다.

```c
// 파일: exit_code.c (실행 오류: 설정 파일이 없습니다)
#include <stdio.h>

int main(void) {
    fprintf(stderr, "설정 파일이 없습니다\n");
    return 1;
}
```

```python
# 파일: exit_code.py (실행 오류: 설정 파일이 없습니다)
import sys

sys.exit("설정 파일이 없습니다")      # 문자열을 주면 표준 오류에 출력하고 종료 코드 1
```

```rust
// 파일: exit_code.rs (실행 오류: 설정 파일이 없습니다)
fn main() {
    eprintln!("설정 파일이 없습니다");
    std::process::exit(1);
}
```

터미널에서 종료 코드는 `echo $?`(macOS·Linux) 또는 `echo $LASTEXITCODE`(Windows PowerShell)로 확인합니다.

## 11. 세 언어 비교

| 관점               | C                   | Python                                      | Rust                               |
| ------------------ | ------------------- | ------------------------------------------- | ---------------------------------- |
| 실행 방식          | 컴파일 → 실행 파일  | 인터프리터가 바로 실행                      | 컴파일 → 실행 파일                 |
| 다른 기능 가져오기 | `#include <헤더>`   | `import 모듈`                               | `use 경로;`                        |
| 시작점             | `int main(void)`    | 파일 맨 위(관례상 `main()` + `if __name__`) | `fn main()`                        |
| 문장 끝            | `;` 필수            | 줄바꿈                                      | `;` (마지막 표현식은 예외, Day 22) |
| 블록               | `{ }`               | 들여쓰기                                    | `{ }`                              |
| 16진수 출력        | `%x`                | `{n:x}`                                     | `{n:x}`                            |
| 2진수 출력         | (C23 이전에는 없음) | `{n:b}`                                     | `{n:b}`                            |
| 실수 기본 출력     | `%f`는 소수 6자리   | 필요한 만큼(`print(3.14)` → `3.14`)         | 필요한 만큼                        |

## 12. 자주 하는 실수

### 실수 1: 세미콜론을 빠뜨린다 (C)

```c
// 파일: no_semicolon.c (컴파일 오류: expected ';')
#include <stdio.h>

int main(void) {
    printf("Hello\n")
    return 0;
}
```

오류가 가리키는 줄의 **앞줄**도 확인하세요.

### 실수 2: #include를 빠뜨린다 (C)

```c
// 파일: no_include.c (컴파일 오류: implicit declaration of function 'printf')
int main(void) {
    printf("Hello\n");
    return 0;
}
```

컴파일러는 `printf`가 무엇인지 모릅니다. 선언이 들어 있는 헤더를 포함하세요.

### 실수 3: 함수 이름 오타 (C)

```c
// 파일: typo.c (컴파일 오류: prinft)
#include <stdio.h>

int main(void) {
    prinft("Hello\n");
    return 0;
}
```

오타 난 이름은 선언이 없으니 컴파일 단계에서 먼저 걸립니다. 경고를 끄고 컴파일하면 링크 단계에서 `undefined reference to 'prinft'`로 다시 걸립니다.

### 실수 4: 서식과 값의 개수가 다르다 (C)

```c
// 파일: missing_arg.c (컴파일 오류: expects a matching 'int' argument)
#include <stdio.h>

int main(void) {
    printf("%d + %d\n", 1);
    return 0;
}
```

### 실수 5: 들여쓰기가 어긋난다 (Python)

```python
# 파일: indent.py (컴파일 오류: IndentationError)
def main():
print("시작")
```

Python에서는 들여쓰기가 C의 중괄호 역할이라, 함수 안쪽 줄을 들여쓰지 않으면 실행 전에 오류가 납니다.

## 13. Q&A

**Q. `int main()`과 `int main(void)`는 다른가요?**

A. C17에서는 `()`가 "인자에 대해 아무것도 말하지 않음"이라서 뜻이 조금 다릅니다. `(void)`가 "인자가 없음"을 정확히 나타내므로 이 과정에서는 `(void)`로 씁니다. C23부터는 둘이 같아졌습니다.

**Q. Python은 컴파일을 전혀 안 하나요?**

A. 내부적으로는 소스를 **바이트코드**라는 중간 형태로 번역한 뒤 실행합니다. 들여쓰기 오류나 괄호 짝 오류 같은 문법 오류는 이 번역 단계에서 걸리기 때문에, 파일의 어느 줄도 실행되기 전에 알려 줍니다.

**Q. 왜 오류 메시지를 표준 출력이 아니라 표준 오류로 보내나요?**

A. `프로그램 > 결과.txt`처럼 출력을 파일에 저장할 때, 오류 메시지까지 결과 파일에 섞이면 곤란하기 때문입니다. 표준 오류는 따로 저장되거나 화면에 그대로 남습니다.

**Q. `printf`와 `puts`는 언제 구별해 쓰나요?**

A. 값을 끼워 넣을 필요가 없는 고정 문자열이면 `puts`가 간단하고 줄바꿈도 붙여 줍니다. 값이 들어가면 `printf`를 씁니다. 사용자에게서 받은 문자열을 `printf(s)`처럼 **서식 문자열 자리에** 넣으면 안 됩니다. `%`가 들어 있으면 오동작하므로 `printf("%s", s)`로 씁니다.

## 14. 핵심 요약

- C 소스는 **전처리(#include) → 컴파일(문법 검사, 기계어) → 링크(라이브러리 연결)** 를 거쳐 실행 파일이 됩니다. Python은 인터프리터가 바로 실행하고, Rust는 C처럼 컴파일합니다.
- C 프로그램은 `main`에서 시작하고, 문장은 세미콜론으로 끝나며, `return 0`은 성공을 뜻하는 종료 코드입니다.
- `printf` 서식: `%d %u %x %o %f %.2f %e %g %c %s %%`. 값의 자료형과 순서를 서식에 맞춥니다.
- Python f-string과 Rust `println!`은 `:` 뒤에 같은 형식 지정(`x`, `o`, `b`, `.2f`/`.2`, `e`, `02X`)을 씁니다. Rust의 `{:?}`는 Debug 형식입니다.
- 글자는 번호(ASCII, 유니코드)로 저장됩니다. `%c`, `chr/ord`, `as u32/as char`로 오갑니다.
- 실패는 표준 오류에 메시지를 쓰고 0이 아닌 종료 코드로 알립니다.
