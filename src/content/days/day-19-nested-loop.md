## 오늘 배울 이유

모든 조합을 나열할 때 바깥 반복 한 번마다 안쪽 반복이 처음부터 실행됩니다. Day 19 "`중첩 반복의 순서`"에서는 Python 코드의 실행 결과(`[(1, 3), (1, 4), (2, 3), (2, 4)]`)를 따라가며, `두 집합의 모든 조합 생성` 동작이 왜 필요한지 확인합니다. 이 동작이 빠지면 "`안쪽 반복이 전체에서 한 번만 실행된다고 생각함`" 같은 문제가 생깁니다.

## 시작 전에 확인할 것

바로 앞선 [Day 18](/learn/day-18-loop-break)에서 배운 "Rust loop와 break 값" 내용을 한 문장으로 말해 보세요. 이번 "`중첩 반복의 순서`"에서 새로 달라지는 조건을 찾아보세요. 핵심 표현은 `for b`입니다.

## 머릿속 그림

바깥 a를 고정하고 안쪽 b의 모든 값을 방문한 다음 a를 바꿉니다. Day 19에서는 아래 흐름 순서대로 상태가 바뀌고, 결과를 가르는 부분은 `for b`입니다.

```text
a=1,b=3  →  a=1,b=4  →  a=2,b=3  →  a=2,b=4
```

위 흐름에서 `for b` 부분이 실행되는 지점을 찾으면 읽는 값과 바뀌는 값이 나뉘어 보입니다. 마지막 출력은 `[(1, 3), (1, 4), (2, 3), (2, 4)]`입니다.

## 천천히 풀어보기

중첩 반복은 바깥쪽 값을 하나 정한 다음 안쪽 반복을 **처음부터 끝까지** 돌립니다. `a`가 1, 2이고 `b`가 10, 20이면 방문 순서는 `(1,10)`, `(1,20)`, `(2,10)`, `(2,20)`입니다. `a`가 한 번 바뀔 때 `b`는 다시 처음부터 시작합니다.

바깥 2번, 안쪽 2번이면 본문은 4번 실행됩니다. 입력이 각각 n개, m개이면 최대 n×m번입니다. 표의 행과 열을 그려 방문 순서를 따라가 보세요. `b`가 비어 있으면 바깥 반복은 돌아도 안쪽 본문은 실행되지 않습니다.

## 문법을 예제로 보기

아래 Python 코드는 Day 19 "`중첩 반복의 순서`"의 독립 예제입니다. 전체 5줄 가운데 핵심 부분은 `for b`이며, 실행 결과는 `[(1, 3), (1, 4), (2, 3), (2, 4)]`입니다.

```python
pairs = []
for a in [1, 2]:
    for b in [3, 4]:
        pairs.append((a, b))
print(pairs)
```

예상 출력:

```text
[(1, 3), (1, 4), (2, 3), (2, 4)]
```

하단 Python 실행 영역에 같은 코드가 들어 있습니다. 먼저 실행 결과(`[(1, 3), (1, 4), (2, 3), (2, 4)]`)를 가리고 예측한 뒤 실행해 비교하세요.

## 핵심 줄 따라 읽기

예제의 핵심 표현은 `for b`입니다. 아래 줄 번호가 붙은 코드에서 이 표현이 있는 줄을 찾으세요.

```python
 1 | pairs = []
 2 | for a in [1, 2]:
 3 |     for b in [3, 4]:
 4 |         pairs.append((a, b))
 5 | print(pairs)
```

1. a=1일 때 b=3·4를 기록합니다
2. a=2일 때 다시 b=3·4를 기록합니다
3. 총 2×2=4쌍입니다

`for b` 부분이 실행될 때 읽는 값과 바뀌는 값을 한 줄씩 적어 보세요. 다음 `결과 예측과 작은 변경`에서는 이 부분이 달라집니다.

## 실행 추적

| 순서 | 상태 또는 동작 |
| ---: | -------------- |
|    1 | a=1,b=3        |
|    2 | a=1,b=4        |
|    3 | a=2,b=3        |
|    4 | a=2,b=4        |

위 순서대로 실행한 최종 출력은 `[(1, 3), (1, 4), (2, 3), (2, 4)]`입니다. `a=1,b=3` 단계와 마지막 단계를 비교하면 입력과 출력의 관계가 보입니다.

## 다른 예제로 다시 이해하기

`for a in [1,2]` 안에 `for b in [3,4,5]`가 있다면 `(1,3), (1,4), (1,5), (2,3), (2,4), (2,5)` 순으로 여섯 번 실행됩니다. 두 번째 바깥 회차에서는 안쪽이 처음인 3부터 다시 시작합니다. 안쪽 모음이 비어 있으면 바깥이 돌아도 짝은 만들어지지 않습니다.

## 결과 예측과 작은 변경

원본 실행 결과는 `[(1, 3), (1, 4), (2, 3), (2, 4)]`입니다. 아래 코드에서 원본과 다른 줄을 먼저 찾으세요.

```python
pairs = []
for a in [2, 2]:
    for b in [3, 4]:
        pairs.append((a, b))
print(pairs)
```

찾은 줄을 적용했을 때의 실행 결과를 먼저 예측해 보세요.

해설: 바뀐 코드의 실행 결과는 아래와 같습니다.

```text
[(2, 3), (2, 4), (2, 3), (2, 4)]
```

원본과 달라졌습니다. 원본 출력은 `[(1, 3), (1, 4), (2, 3), (2, 4)]`입니다. 다른 줄(`for a in [1, 2]:` → `for a in [2, 2]:`)에서 시작된 차이가 이후 흐름을 타고 최종 출력에 반영되었습니다. 원본 추적(`a=1,b=3` → …)과 바뀐 줄부터 대조해 보세요.

## 자주 틀리는 지점

**확인할 실수: 안쪽 반복이 전체에서 한 번만 실행된다고 생각함.** 정상 코드의 실행 결과는 `[(1, 3), (1, 4), (2, 3), (2, 4)]`입니다.

- 정상 줄: `for b in [3, 4]:`
- 잘못된 줄: `for a in [3, 4]:`

두 줄을 나란히 놓고 `바깥 a를 고정하고 안쪽 b의 모든 값을 방문한 다음 a를 바꿉니다.` 기준으로 어느 쪽이 맞는지 설명하세요. 결과가 예상과 다르면 `a=1,b=3`부터 `[(1, 3), (1, 4), (2, 3), (2, 4)]`까지 처음 어긋난 곳을 찾습니다.

## 다른 언어로 옮기기

세 언어에서 지켜야 할 핵심 동작은 `두 집합의 모든 조합 생성`입니다. 목표는 같은 입력에 같은 결과를 내는 것으로, 각 언어의 규칙에 맞게 옮겼는지 실행 결과로 대조하세요.

| 언어   | 옮길 때 확인할 표현과 규칙    |
| ------ | ----------------------------- |
| C17    | 바깥 for 안에 안쪽 for        |
| Python | 들여쓴 두 개의 for            |
| Rust   | for a in ... { for b in ... } |

C17에서는 `바깥 for 안에 안쪽 for` 규칙을 적용합니다. "`중첩 반복의 순서`" 수업의 실행 결과(`[(1, 3), (1, 4), (2, 3), (2, 4)]`)를 기준으로 삼고, C는 범위와 널 검사를 자동으로 해 주지 않으므로, 코드에 사용된 접근마다 유효 범위를 직접 확인해야 합니다. Python에서는 `들여쓴 두 개의 for` 규칙을 따릅니다. 실패나 빈 입력은 예외로 드러내며 조용히 넘기지 마세요. Rust에서는 `for a in ... { for b in ... }` 규칙을 따릅니다. 실행 결과가 다르면 컴파일 오류(타입, 소유권, 빌림)와 실행 때 패닉(인덱스 범위 등) 중 어느 쪽인지 메시지부터 구분하세요.

## 실습 순서

예측(`[(1, 3), (1, 4), (2, 3), (2, 4)]` 맞히기) → 빈칸(`for b` 채우기) → 변경(`처음 등장하는 숫자를 1에서 2로`) → 오류 수정(`안쪽 반복이 전체에서 한 번만 실행된다고 생각함` 찾기) → 독립 구현(`'중첩 반복의 순서' 개념을 보여주는 작은 프로그램` 만들기) 순으로 진행하세요. 각 단계의 답은 본문의 `[(1, 3), (1, 4), (2, 3), (2, 4)]` 및 `for b` 설명과 대조하세요.

## 스스로 설명하기

- "`중첩 반복의 순서`" 수업이 필요한 이유는 `두 집합의 모든 조합 생성` 동작으로 설명해 보세요.
- 예제에서 `for b` 부분 실행 직전의 상태와 직후의 출력(`[(1, 3), (1, 4), (2, 3), (2, 4)]`)을 말해 보세요.
- "`안쪽 반복이 전체에서 한 번만 실행된다고 생각함`" 상황에서 어떤 입력과 출력이 어긋나는지 말해 보세요.
- 같은 `두 집합의 모든 조합 생성` 동작을 나머지 두 언어의 어떤 표현으로 옮길지 말해 보세요.
