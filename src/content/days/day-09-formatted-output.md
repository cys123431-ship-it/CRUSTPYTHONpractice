## 1. 오늘 배울 내용

Day 3에서 `%d`, `%.2f` 같은 서식을 배웠습니다. 오늘은 여기에 **몇 칸에, 어느 쪽으로, 무엇으로 채워서** 출력할지를 더해 **칸이 맞는 표**를 만듭니다.

1. 형식 지정의 여덟 가지 구성 요소:
   - 채움 문자
   - 정렬
   - 부호
   - 0 채우기
   - 너비
   - 천 단위 구분
   - 자릿수
   - 종류
2. 세 언어의 형식 문법을 나란히 비교합니다.
   - Python: `{값:명세}`
   - C: `%플래그너비.자릿수종류`
   - Rust: `{:명세}`
3. **너비를 변수로** 정하는 방법을 배웁니다.
4. 영수증, 점수표, 환율표를 출력해 봅니다.
5. **한글이 섞이면 표가 어긋나는 이유**를 이해하고 해결합니다.

## 2. 왜 필요한가

계산이 맞아도 출력이 읽기 어려우면 쓸모가 반으로 줄어듭니다.

```text
정렬 없이                         정렬해서
Americano 4500 2 9000             item         price qty   total
Latte 5000 1 5000                 Americano    4,500   2   9,000
Bagel 3800 3 11400                Latte        5,000   1   5,000
                                  Bagel        3,800   3  11,400
```

오른쪽 표는 숫자의 자리가 세로로 맞아 크기를 한눈에 비교할 수 있습니다. 영수증, 성적표, 실험 결과, 로그 파일처럼 사람이 읽는 출력에는 칸 맞춤이 거의 항상 필요합니다. 또 자릿수를 정하면 `0.30000000000000004` 같은 실수 오차를 감추고 필요한 정밀도만 보여 줄 수 있습니다.

## 3. 그림으로 이해하기

"너비 8칸"은 값이 들어갈 **상자 8칸**을 준비하는 것입니다. 정렬은 값을 상자의 어느 쪽에 붙일지, 채움은 남은 칸을 무엇으로 채울지 정합니다.

```text
값 42, 너비 8

오른쪽 정렬 {:>8}   [ · · · · · · 4 2 ]   →  "      42"
왼쪽 정렬   {:<8}   [ 4 2 · · · · · · ]   →  "42      "
가운데      {:^8}   [ · · · 4 2 · · · ]   →  "   42   "
0 채우기    {:08}   [ 0 0 0 0 0 0 4 2 ]   →  "00000042"
* 채우기+가운데 {:*^8} [ * * * 4 2 * * * ] →  "***42***"
```

Python 형식 명세의 구성 요소는 이 순서로 씁니다(Rust도 거의 같습니다).

```text
{ 값 : 채움 정렬 부호 # 0 너비 , .자릿수 종류 }
          *    ^    +   #  0  10   ,  .2    f
예) {n:*^+10,.2f}  →  채움 *, 가운데, 부호 표시, 너비 10, 천 단위, 소수 2자리, 실수
```

C는 `%` 뒤에 **플래그 → 너비 → .자릿수 → 종류** 순서로 씁니다.

```text
% [플래그] [너비] [.자릿수] 종류
    -       10      .2       f       → %-10.2f : 10칸 왼쪽 정렬, 소수 2자리 실수
```

## 4. 천천히 풀어보기

### 4.1 구성 요소별 비교

| 하고 싶은 일        | Python           | C                 | Rust          | 42 또는 3.14159로     |
| ------------------- | ---------------- | ----------------- | ------------- | --------------------- |
| 너비 8, 오른쪽      | `{x:>8}`         | `%8d`             | `{:>8}`       | `      42`            |
| 너비 8, 왼쪽        | `{x:<8}`         | `%-8d`            | `{:<8}`       | `42      `            |
| 너비 8, 가운데      | `{x:^8}`         | (없음)            | `{:^8}`       | `   42   `            |
| 0으로 채우기        | `{x:08}`         | `%08d`            | `{:08}`       | `00000042`            |
| 다른 문자로 채우기  | `{x:*^8}`        | (없음)            | `{:*^8}`      | `***42***`            |
| 항상 부호           | `{x:+}`          | `%+d`             | `{:+}`        | `+42`                 |
| 양수 앞 공백        | `{x: }`          | `% d`             | (없음)        | ` 42`                 |
| 소수점 2자리        | `{x:.2f}`        | `%.2f`            | `{:.2}`       | `3.14`                |
| 너비 10, 소수 3자리 | `{x:10.3f}`      | `%10.3f`          | `{:10.3}`     | `     3.142`          |
| 천 단위 쉼표        | `{x:,}`          | (표준에 없음)     | (표준에 없음) | `1,234,567`           |
| 지수 표기           | `{x:.2e}`        | `%.2e`            | `{:.2e}`      | `1.23e+06` / `1.23e6` |
| 퍼센트              | `{x:.1%}` (×100) | (직접 ×100, `%%`) | (직접)        | `25.6%`               |
| 16진수 + 접두사     | `{x:#x}`         | `%#x`             | `{:#x}`       | `0xff`                |

기본 정렬은 **숫자는 오른쪽, 글자는 왼쪽**입니다(세 언어 공통). 그래서 표를 만들 때 숫자에는 따로 정렬 기호를 쓰지 않아도 됩니다.

### 4.2 너비는 "최소" 칸 수

값이 너비보다 길면 **잘리지 않고** 전부 출력됩니다. 표에서 긴 값 하나가 칸을 밀어내는 이유입니다. 반대로 **문자열의 자릿수**(`{s:.2}`, `%.2s`)는 "최대 글자 수"라서 잘라 냅니다.

### 4.3 너비를 변수로

표의 칸 너비를 한 곳에서 바꾸고 싶을 때 씁니다.

| 언어   | 쓰는 법             | 예                                   |
| ------ | ------------------- | ------------------------------------ |
| Python | 명세 안에 또 중괄호 | `f"{pi:{width}.{digits}f}"`          |
| C      | `*` 자리에 인자로   | `printf("%*.*f", width, digits, pi)` |
| Rust   | 이름 뒤에 `$`       | `println!("{pi:width$.digits$}")`    |

### 4.4 바이트, 글자, 화면 칸

한글이 섞이면 "길이"를 세는 방법이 세 가지로 갈립니다.

| 문자열   | 바이트 수(UTF-8) | 글자 수 | 화면에서 차지하는 칸 |
| -------- | ---------------: | ------: | -------------------: |
| `"ab"`   |                2 |       2 |                    2 |
| `"가나"` |                6 |       2 |                    4 |

- **C**의 `printf`는 **바이트 수**로 너비를 맞춥니다. `%-6s`에 `"가나"`를 주면 이미 6바이트라 공백을 하나도 붙이지 않습니다.
- **Python**과 **Rust**는 **글자 수**로 맞춥니다. `"가나"`에 공백 4개를 붙여 6"글자"로 만듭니다.
- 그런데 한글은 고정폭 글꼴에서 **2칸**을 차지해서, 어느 쪽도 영문과 칸이 맞지 않습니다.

해결하려면 "화면 칸 수"를 직접 계산해 공백을 채워야 합니다. 9절에서 해 봅니다. 가장 간단한 해결은 **정렬이 필요한 칸에는 영문·숫자만 쓰는 것**입니다. 이 과정의 C 예제들이 칸을 맞추는 곳에 영문 제목을 쓰는 이유입니다.

## 5. C로 구현하기

```c
// 파일: formats.c
#include <stdio.h>

int main(void) {
    double pi = 3.14159265;
    printf("[%f] [%.2f] [%10.3f] [%-10.3f] [%010.3f]\n", pi, pi, pi, pi, pi);
    printf("[%d] [%8d] [%-8d] [%08d] [%+d] [% d]\n", 42, 42, 42, 42, 42, 42);
    printf("[%e] [%.2e] [%g] [%g]\n", 1234567.0, 1234567.0, 0.0001, 1234567.0);
    printf("[%*d] [%.*f]\n", 6, 42, 3, pi);          // 너비·자릿수를 인자로
    printf("[%x] [%#x] [%08X] [%#o]\n", 255, 255, 255, 8);
    printf("[%5s] [%-5s] [%.2s]\n", "ab", "ab", "abcdef");

    printf("------------------------------\n");
    printf("%-10s%8s%4s%8s\n", "item", "price", "qty", "total");
    printf("%-10s%8d%4d%8d\n", "Americano", 4500, 2, 4500 * 2);
    printf("%-10s%8d%4d%8d\n", "Latte", 5000, 1, 5000 * 1);
    printf("%-10s%8d%4d%8d\n", "Bagel", 3800, 3, 3800 * 3);
    printf("------------------------------\n");
    printf("%-22s%8d\n", "TOTAL", 9000 + 5000 + 11400);

    printf("[%-6s] [%-6s]\n", "ab", "가나");          // 바이트 수로 맞춘다
    return 0;
}
```

### 코드 한 부분씩 읽기

| 코드                       | 설명                                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------------------- |
| `%f` → `3.141593`          | 자릿수를 정하지 않으면 C는 소수점 아래 **6자리**를 씁니다.                                        |
| `%-10.3f`                  | `-`는 왼쪽 정렬, 10은 너비, `.3`은 소수 3자리입니다.                                              |
| `%010.3f`                  | 너비 앞의 `0`은 빈칸을 0으로 채웁니다. 소수점도 한 칸을 차지해 `000003.142`가 10칸입니다.         |
| `% d`                      | 양수 앞에 공백을 둬서 음수(`-42`)와 자리를 맞춥니다.                                              |
| `%g`                       | `%f`와 `%e` 중 짧은 쪽을 고르고 유효숫자 6개를 씁니다. `1234567.0`은 7자리라 지수 표기가 됩니다.  |
| `%*d`, `%.*f`              | `*` 자리에 들어갈 값(너비 6, 자릿수 3)을 출력할 값보다 **먼저** 인자로 넘깁니다.                  |
| `%#x`, `%#o`               | `#`은 진법 접두사(`0x`, `0`)를 붙입니다.                                                          |
| `%.2s`                     | 문자열에서 앞의 2바이트만 출력합니다. 한글은 한 글자가 3바이트라 `%.2s`로 자르면 글자가 깨집니다. |
| `%-10s%8s%4s%8s`           | 표의 칸 너비입니다. 제목 줄과 내용 줄이 **같은 너비**를 써야 칸이 맞습니다.                       |
| `printf("[%-6s]", "가나")` | 바이트 기준이라 공백이 붙지 않습니다(4.4절).                                                      |

C 표준 `printf`에는 천 단위 구분 기능이 없습니다. 일부 시스템(POSIX)은 `%'d` 플래그를 지원하지만, 이식성이 없어 이 과정에서는 쓰지 않습니다.

## 7. Rust로 구현하기

Rust의 형식 문법은 Python과 매우 비슷하지만, 실수의 자릿수에 `f`를 붙이지 않고(`{:.2}`), 천 단위 구분과 `%` 종류가 없습니다.

```rust
// 파일: formats.rs
fn main() {
    let pi = 3.14159265_f64;
    println!("[{pi}] [{pi:.2}] [{pi:10.3}] [{pi:<10.3}] [{pi:^10.3}] [{pi:010.3}]");
    println!("[{:+}] [{:>8}] [{:<8}] [{:08}] [{:*^8}]", 42, 42, 42, 42, "ab");
    println!("[{:e}] [{:.2e}]", 1234567.0_f64, 1234567.0_f64);

    let width = 10;
    let digits = 2;
    println!("[{pi:width$.digits$}] [{:>width$}]", 42);   // 너비·자릿수를 변수로
    println!("[{:#x}] [{:#b}] [{:08b}]", 255, 5, 5);
    println!("[{:?}] [{:>6}]", "ab", "ab");

    println!("{}", "-".repeat(30));
    println!("{:<10}{:>8}{:>4}{:>8}", "item", "price", "qty", "total");
    println!("{:<10}{:>8}{:>4}{:>8}", "Americano", 4500, 2, 4500 * 2);
    println!("{:<10}{:>8}{:>4}{:>8}", "Latte", 5000, 1, 5000 * 1);
    println!("{:<10}{:>8}{:>4}{:>8}", "Bagel", 3800, 3, 3800 * 3);
    println!("{}", "-".repeat(30));
    println!("{:<22}{:>8}", "TOTAL", 9000 + 5000 + 11400);

    println!("[{:<6}] [{:<6}]", "ab", "가나");               // 글자 수로 맞춘다
    println!("{} {}", "가나".chars().count(), "가나".len());  // 글자 수, 바이트 수
}
```

## 9. 다른 예제로 다시 이해하기

**C로 환율표 만들기.** 10만 원을 여러 나라 돈으로 바꾸는 표입니다. 통화 코드는 왼쪽, 숫자는 오른쪽에 맞추고, 모든 숫자를 소수 2자리로 통일했습니다.

```c
// 파일: exchange.c
#include <stdio.h>

int main(void) {
    double won = 100000;
    printf("%-6s %10s %12s\n", "code", "rate", "amount");
    printf("%-6s %10.2f %12.2f\n", "USD", 1385.50, won / 1385.50);
    printf("%-6s %10.2f %12.2f\n", "JPY", 9.21, won / 9.21);
    printf("%-6s %10.2f %12.2f\n", "EUR", 1502.30, won / 1502.30);
    return 0;
}
```

실행 결과:

```text
code         rate       amount
USD       1385.50        72.18
JPY          9.21     10857.76
EUR       1502.30        66.56
```

소수점이 세로로 한 줄에 맞춰져서 크기를 비교하기 쉽습니다. 너비를 넉넉히 잡아야 가장 긴 값(10857.76)이 칸을 밀어내지 않습니다.

**Python으로 한글 표 맞추기.** 이름이 한글이면 `{name:<8}`로는 칸이 맞지 않습니다. 화면 칸 수를 계산하는 작은 함수를 만들어 봅시다. 한글 한 글자는 UTF-8로 3바이트, 영문은 1바이트라는 점을 이용하면, 한글과 영문만 섞인 문자열의 **화면 칸 수 = 글자 수 + (바이트 수 − 글자 수) ÷ 2**로 계산할 수 있습니다. 한글 k글자, 영문 a글자라면 (3k + a − k − a) ÷ 2 = k이니, 글자 수에 한글 글자 수를 한 번 더 더하는 셈입니다.

```python
# 파일: korean_table.py
def screen_width(text):
    """한글은 2칸, 영문·숫자는 1칸으로 센다(한글과 영문만 있다고 가정)."""
    return len(text) + (len(text.encode("utf-8")) - len(text)) // 2


def left(text, cols):
    return text + " " * (cols - screen_width(text))


print("글자 수로 맞춘 표:")
print(f"{'이름':<8}|{'점수':>6}|")
print(f"{'민지':<8}|{92.5:>6.1f}|")
print(f"{'Alice':<8}|{78:>6.1f}|")
print()
print("화면 칸 수로 맞춘 표:")
print(left("이름", 8) + "|" + " " * (6 - screen_width("점수")) + "점수|")
print(left("민지", 8) + "|" + f"{92.5:>6.1f}|")
print(left("Alice", 8) + "|" + f"{78:>6.1f}|")
print(left("김수한무", 8) + "|" + f"{88.25:>6.1f}|")
```

실행 결과:

```text
글자 수로 맞춘 표:
이름      |    점수|
민지      |  92.5|
Alice   |  78.0|

화면 칸 수로 맞춘 표:
이름    |  점수|
민지    |  92.5|
Alice   |  78.0|
김수한무|  88.2|
```

고정폭 글꼴(코드 편집기, 터미널)에서 보면 위 표는 `|`가 어긋나고, 아래 표는 세로로 맞습니다. `88.25`가 `88.2`로 출력된 것은 절반을 짝수 쪽으로 반올림하기 때문입니다(Day 6). `def`로 함수를 만드는 방법은 Day 20~23에서 자세히 배웁니다. 이모지나 일본어처럼 다른 글자가 섞이면 이 계산이 틀릴 수 있어서, 실제 프로그램에서는 `unicodedata.east_asian_width()`나 `wcwidth` 같은 도구를 씁니다.

함수가 계산한 칸 수를 직접 확인해 봅시다.

```python
# 파일: width_check.py
def screen_width(text):
    return len(text) + (len(text.encode("utf-8")) - len(text)) // 2


print(screen_width("민지"), screen_width("Alice"), screen_width("김수한무"))
```

실행 결과:

```text
4 5 8
```

`민지`는 2글자지만 화면에서 4칸입니다.

| 실수 자릿수 | `.2f`             | `.2f`         | `.2`                            |
| 천 단위     | `,` `_`           | 없음          | 없음                            |
| 퍼센트      | `%`               | 없음          | 없음                            |
| 진법        | `x X o b`, `#`    | `x X o`, `#`  | `x X o b`, `#`                  |
| 너비 기준   | 글자 수           | **바이트 수** | 글자 수                         |

## 11. 세 언어 비교

| 관점             | Python                            | C                       | Rust                                       |
| ---------------- | --------------------------------- | ----------------------- | ------------------------------------------ |
| 형식 검사        | 실행 중(잘못된 명세는 ValueError) | 컴파일 경고(`-Wformat`) | 컴파일 오류(형식 문자열을 컴파일러가 검사) |
| 실수 기본 출력   | 가장 짧은 정확한 표현             | 소수 6자리(`%f`)        | 가장 짧은 정확한 표현                      |
| 가운데 정렬·채움 | 있음                              | 없음                    | 있음                                       |
| 천 단위 구분     | 있음                              | 없음(POSIX `%'d`)       | 없음(직접 구현)                            |
| 지수 표기        | `1.23e+06`                        | `1.23e+06`              | `1.23e6`                                   |

## 12. 자주 하는 실수

### 실수 1: C에서 % 기호를 하나만 쓴다

```c
// 파일: lone_percent.c (컴파일 오류: unknown conversion type character)
#include <stdio.h>

int main(void) {
    printf("달성률 %d%\n", 50);
    return 0;
}
```

퍼센트 기호 자체는 `%%`입니다.

### 실수 2: 정수에 실수 형식을 쓴다 (Python)

```python
# 파일: wrong_code.py (실행 오류: ValueError)
print(f"{3.14:d}")
```

```text
ValueError: Unknown format code 'd' for object of type 'float'
```

실수는 `f`, `e`, `g`, `%`를, 정수는 `d`, `x`, `b` 등을 씁니다. 반대로 정수에 `.2f`는 괜찮습니다(`f"{5:.2f}"` → `5.00`).

### 실수 3: Rust에서 너비 변수에 $를 빠뜨린다

```rust
// 파일: missing_dollar.rs (컴파일 오류: unknown format trait `width`)
fn main() {
    let width = 6;
    println!("[{:width}]", 42);
}
```

`:` 뒤의 이름은 **형식 종류**(`x`, `b`, `e` 같은)로 해석됩니다. `{:width$}`로 씁니다.

### 실수 4: 너비가 값보다 짧다

```python
# 파일: too_narrow.py
print(f"[{12345:3}] [{'abcdef':3}] [{'abcdef':.3}]")
```

실행 결과:

```text
[12345] [abcdef] [abc]
```

너비는 최소 칸 수라 잘리지 않고, 문자열의 `.3`만 잘라 냅니다. 표를 만들 때는 **가장 긴 값**에 맞춰 너비를 정하세요.

### 실수 5: 한글이 섞인 칸을 정렬한다

4.4절과 9절처럼 칸이 어긋납니다. 정렬할 칸에는 영문을 쓰거나 화면 칸 수를 직접 계산하세요.

## 13. Q&A

**Q. Python의 `format()`, `%` 방식, f-string 중 무엇을 써야 하나요?**

A. 세 가지 모두 같은 형식 명세를 씁니다(`%` 방식은 C 문법). 새 코드에서는 가장 읽기 쉬운 f-string을 쓰세요. `"{:>8}".format(x)`는 형식 문자열을 변수에 담아 두고 여러 번 쓸 때 편리합니다.

**Q. Rust에서 천 단위 쉼표는 어떻게 넣나요?**

A. 표준 라이브러리에는 없습니다. 숫자를 문자열로 바꾼 뒤 뒤에서부터 세 글자마다 쉼표를 끼우는 함수를 직접 만들거나, 외부 라이브러리를 씁니다. 문자열 다루기를 배운 뒤(Day 39) 도전해 보세요.

**Q. 왜 표에서 숫자는 오른쪽 정렬이 좋나요?**

A. 오른쪽에 맞추면 일의 자리, 십의 자리, 소수점이 세로로 맞아 크기를 한눈에 비교할 수 있습니다. 글자는 첫 글자부터 읽으므로 왼쪽 정렬이 자연스럽습니다.

**Q. 출력 모양을 정할 때 값을 반올림해 두는 것과 무엇이 다른가요?**

A. 형식 지정은 **보여 주는 모양**만 바꾸고 값은 그대로 둡니다. `round()`로 값을 바꾸면 그 뒤의 계산에도 영향을 줍니다. 계산은 원래 값으로 하고, 출력할 때만 자릿수를 정하는 것이 오차를 줄이는 방법입니다.

## 14. 핵심 요약

- 형식 지정은 **채움·정렬·부호·0·너비·천 단위·자릿수·종류**로 이루어집니다. Python과 Rust는 `{:명세}`, C는 `%플래그너비.자릿수종류`입니다.
- 정렬: `<` 왼쪽, `>` 오른쪽, `^` 가운데(C는 `-`로 왼쪽만). 기본은 숫자 오른쪽, 글자 왼쪽입니다.
- 너비는 **최소** 칸 수라 긴 값은 잘리지 않습니다. 문자열의 자릿수는 최대 글자 수입니다.
- 너비를 변수로: Python `{x:{w}}`, C `%*d`, Rust `{x:w$}`.
- 천 단위 쉼표와 `%` 형식은 Python에만 있습니다. Rust 실수 자릿수는 `.2`(f 없음), 지수는 `e6` 모양입니다.
- C는 **바이트 수**, Python·Rust는 **글자 수**로 너비를 맞추고, 한글은 화면에서 2칸이라 셋 다 어긋납니다.
