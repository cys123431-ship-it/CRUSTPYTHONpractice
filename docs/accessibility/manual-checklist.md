# Manual accessibility checklist

- [ ] Traverse Dashboard → Lesson → practice → quiz → complete using keyboard only.
- [ ] Confirm visible focus is never clipped by sticky navigation.
- [ ] At 200% zoom, confirm no text overlap and comparison tables remain reachable.
- [ ] With a screen reader, confirm code editor labels, execution status, quiz feedback, and completion status.
- [ ] With reduced motion enabled, confirm no essential information depends on animation.
- [ ] At 360 px and with the mobile keyboard open, confirm editor controls and footer remain reachable.
- [ ] Verify success/error meaning is present in text, not color alone.
